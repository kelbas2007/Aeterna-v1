# AETERNA-v1

**Единый Rust/EvoPhase/U1 когнитивный runtime без LLM**, CPU-first.
Бинарник `aeterna-v1`; `aeterna-unified` — совместимое имя того же
исполняемого кода. Совместный владелец памяти и защиты — `ScientificRuntime`.

**Реализован общий обучающийся контур v2:** исходные изображения и сигналы,
обучаемая история, модель последствий, память опыта, цели и консолидация
в одном `ScientificRuntime`, с выбором действий через U1. Состояние сохраняется
и продолжает прежнюю жизнь. [Запуск и архитектура](docs/LEARNING_ORGANISM.md) ·
[проверки и результаты](docs/LEARNING_ORGANISM_RESULT.md) ·
[обзор исследований мозга](docs/BRAIN_ARCHITECTURE_REVIEW_20261021.md).
Общий интеллект и улучшение рекурсивного производителя пока не квалифицированы.
Открытый запуск продолжил прежнюю жизнь до 17 990 переходов. Преимущество
не достигнуто: на реальных сигналах сеть проиграла прогнозу последнего значения;
во внешнем симуляторе обучение требует отдельной проверки эффективности.

[Аудит архитектуры перед следующим экспериментом](docs/ARCHITECTURE_AUDIT_20261021.md):
проверенные причины неудач рекурсии, время фиксации прогнозов, существующие
наработки и применимые открытые подходы. [Протокол проверки исправления](docs/FIRST_READOUT_PROTOCOL.md).

**Последняя проверка памяти целого организма:** два продолжения одного ученика
до 22 101 действия. На новых 512 примерах каждого корпуса после обучения:
MNIST 364, HAR 260, Fashion 356; удержание относительно родителя пройдено.
Новая статистическая консолидация не превзошла прежнюю память: ответы совпали,
работа выросла на 10,88%. Основным по заданному критерию остаётся PR18 parent.
[Полный результат и сохранённые жизни](docs/CONSOLIDATED_MEMORY_RESULT.md) ·
[предыдущая неудачная политика покрытия](docs/COVERAGE_MEMORY_RESULT.md).

**Основной опубликованный организм:** 17 798 действий, один сохраняемый
ученик через изображения, сигналы и навигацию. На новых тестовых цифрах —
163/256 против 30/256 без приобретения новых классов; удержание прежних навыков
не прошло проверку. Общий конструктор за эту жизнь не запускался, библиотека
VM пуста, новой поисковой политики RSP2 нет. [Результаты, причины в коде и живое состояние](docs/FIRST_READOUT_RESULT.md).

**Предыдущая опубликованная жизнь с приобретаемыми правилами:** один ученик прошёл
11 174 действия через изображения, сигналы и навигацию, сохраняя общую память,
U1, RSP2 и приобретённую условную программу в одном живом checkpoint.
На следующей части жизни — 5321 внешнее действие против 5905 у прежней системы;
первые ответы 1158/1696 против 1159/1696. Превосходство по точности не доказано.
[Полная жизнь, контрольные сравнения и обучающееся состояние](docs/ACQUIRED_RULES_RESULT.md).

**Общий жизненный цикл сенсорного ученика:** `organism_init` связывает его
фактический опыт, прежний RSP2 и пересмотр оценщика действий. Один сохраняемый
экземпляр проходит изображения, сигналы, навигацию и возврат к прежнему опыту.
[Запуск, проверка поведения и границы](docs/ORGANISM_LIFETIME.md).
[Предыдущая проверка общей жизни](docs/ORGANISM_LIFETIME_RESULT.md): 2200 действий на вариант,

## Общий ученик для внешних сенсоров

Новый общий сенсорный контур описан в
[EXTERNAL-CONTINUAL-5](docs/EXTERNAL_CONTINUAL5.md): один сохраняемый ученик,
награды без заданного вектора цели, рабочая память объектов и ограниченное

не подменяет результаты оценки; это не заявление об общем интеллекте.

## Начало работы

Нужны Rust **1.99.0**, зависимости из `Cargo.lock`.

```bash
cargo run --locked -- --help
cargo run --locked -- --status
cargo run --locked -- --jsonl
cargo run --locked -- --inspect path/to/checkpoint.json
python scripts/check_project.py
python scripts/check_docs.py
```

`--status` сообщает о функциях, не об уже выученных знаниях.
`--inspect` только читает указанный checkpoint. В JSONL действия исполняет
**доверенный виртуальный мир**, а реальные последствия возвращаются через
POST. HumanProtection выдаёт новое разрешение для каждого шага.

JSONL `init` по умолчанию использует `planning_depth=2`; теперь глубину и
вычислительный бюджет можно задать явно. Исторические результаты 3–5
действий относятся к прежним Rust-конфигурациям.
[Руководство JSONL](docs/JSONL_AUTONOMOUS_OPTIONS.md).

## Что объединено

EvoPhase/U1, фактический защищённый Learner, EP1, School/SG1, REL1,
RSP2, кандидатные RSP3 и LC1, исследовательские причинные пробы,
приобретённые последовательности действий, ограниченный выбор глубины
памяти и доказательная проверка необходимости усложнения. RSP2
сохраняет свои критерии принятия поисковых улучшений; кандидат не получает
автоматически право на внешние действия.
