# AETERNA-v1

Исследовательский когнитивный runtime на Rust без LLM.
**Один проект, основная программа `aeterna-v1`, владелец состояния ScientificRuntime.**
`aeterna-unified` сохранено как совместимое имя для существующих адаптеров.

## Запуск

Нужен Rust 1.99.0; toolchain и зависимости закреплены в репозитории.

```text
cargo run --locked -- --help
cargo run --locked -- --status
cargo run --locked -- --inspect learned-state.json
cargo run --locked -- --school learned-state.json
cargo run --locked -- --relations learned-state.json
```

Checkpoint указывается явно. `--status` показывает состав реализации, а не
приобретённые знания. `--inspect` проверяет сохранённое состояние без изменений.
Для машинного интерфейса: `aeterna-v1 --jsonl`. Виртуальный адаптер не предназначен
для управления реальным оборудованием. Windows-пакеты находятся в артефактах CI.

## Что входит

Защищённое взаимодействие, EvoPhase/U1, построение программ, EP1, учебная память,
композиция SG1, отношения величин REL1, рекурсивный поиск RSP2 доступны через
общий runtime. **Объединение реализации не доказывает полноценный интеллект.**
Не все дополнительные нейронные режимы совместимы в одной сессии.

RSP3 добавляет экспериментальный подбор исполняемой поисковой политики из результатов
реальных поисков. Он выдаёт кандидата, не изменяя действующую RSP2 без её
проверок производителя и сохранности. Результат: [RSP3](docs/RSP3_EXPERIENCE_RESULTS.md).

**LC1 — центральный механизм приобретения недостающих вычислений.**
Он обучает обратные зависимости из выполненных операций, самостоятельно
предлагает ограниченные промежуточные выражения и проверяет их прямой VM.
Приобретённые правила сохраняются в том же checkpoint, что RSP2/U1/School;
доступны как опциональная операция общего JSONL, а не отдельный организм.
[LC1: реализация и границы](docs/LC1_INTEGRATION.md),
[исходная исследовательская идея](docs/LC1_PROTOCOL.md).

RSP2 проверяет перенос, сохранность решённых задач и роль производителя потомков.
Его локальный экзамен: 120/384 против cold 121/384; общего преимущества нет.
Ранее ARC-AGI-3: 0/7; REL1: 224/1000 на уже использованном SVAMP.
Исторические вердикты не заменяются успешными сборками.

## Проверка

```text
python scripts/check_project.py
```

Единый CI проверяет Linux/Windows и общий checkpoint. Обычные и причинные
регрессии: `bash scripts/check.sh`. Демонстрации: `bash scripts/demo.sh`.
Одноразовые квалификации этими командами не запускаются. Прежняя демонстрация
мотора: `cargo run --locked --example legacy_motor_demo`.
