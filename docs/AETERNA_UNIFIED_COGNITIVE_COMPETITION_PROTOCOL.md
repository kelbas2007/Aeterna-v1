# AETERNA — UNIFIED COGNITIVE COMPETITION ARCHITECTURE

Status: architectural redesign specification after final AETERNA-v1 INTEL-1 FAIL
Date: 2026-10-07

## Goal

Do not add another cognitive organ.

Replace the fixed host-owned ordering between existing cognitive mechanisms with one carrier-owned competition over candidate internal/external operations.

The redesign preserves proven AETERNA-v1 substrate capabilities but changes who decides what the organism thinks about next.

## Preserved components

Keep, subject to regression:
- phase-native transition/value recurrence;
- persistent physical checkpoint state;
- learned epistemic drive;
- recursive/self-selected abstraction;
- goal relevance;
- rival prediction provenance and revision;
- contextual history;
- evidence-gated perceptual variables;
- compositional perceptual programs;
- Human Protection boundary.

No AETERNA-v1 INTEL verdict is relabeled.

## Remove as cognitive authority

The new cognition must not depend on a Rust priority chain equivalent to:

compositional -> perceptual -> contextual -> rival -> goal-active -> general exploration.

The host may enumerate physically active proposals for transport/debugging, but it may not decide winner by module identity or authored priority.

## Unified cognitive proposal

Every acquired explanatory structure may emit a physically represented proposal with task-agnostic fields:

- operation/action reference;
- expected goal value;
- epistemic value;
- predictive confidence;
- contradiction/residual pressure;
- evidence quality;
- execution/computation cost;
- structural/resource cost;
- applicability/coherence.

The fields must be derived from carrier state. No world ID, task ID, representation-class priority or evaluator answer is allowed.

## Competition

A shared carrier competition layer selects one proposal.

Required properties:
1. physically causal: lesion/phase intervention changes proposal winner;
2. learned/adaptive weighting rather than fixed module priority;
3. disagreement remains representable rather than silently overwritten;
4. stale hypotheses lose action authority without losing provenance;
5. previously useful dormant hypotheses can reactivate when matching evidence returns;
6. internal thought operations and external motors use the same competition principle;
7. Human Protection remains an external non-bypassable gate after external motor selection.

## Hypothesis ecology

All candidate explanations share one lifetime resource economy.

Each candidate has:
- identity/provenance;
- evidence;
- applicability;
- utility history;
- current activation;
- contradiction history;
- dependency references;
- dormancy/retirement state.

Context split, perceptual feature, compositional predicate and rival law are different structure types but participate in the same competition/evidence economy.

No candidate may monopolize behavior merely because its API is checked first.

## Architecture Gate U1 — meta-control ownership

Construct a world in which at least three previously qualified operations are simultaneously plausible:
- general epistemic exploration;
- rival discrimination;
- representation refinement.

PASS requires the selected operation to be determined by carrier-owned proposal competition.

Controls:
- remove host priority ordering entirely;
- lesion/phase-shift the winning meta-control pathway -> winner changes or no valid winner;
- exact restore -> original winner returns;
- task labels and module-name scores forbidden.

## Architecture Gate U2 — lifetime hypothesis ecology

One persistent organism accumulates:
- useful old hypothesis;
- stale one-sided candidate;
- irrelevant candidate;
- later useful competing hypothesis.

PASS requires:
- stale/irrelevant candidates stop monopolizing action without deletion of provenance;
- useful old hypothesis reactivates when its evidence pattern returns;
- candidate utility/dormancy changes are carrier-owned;
- no evaluator world-change/reset signal.

## Architecture Gate U3 — cross-mechanism residual allocation

Present residuals compatible with multiple explanation classes:
- missing history;
- missing raw feature;
- wrong transition law.

The organism must allocate experiments among them using the same carrier-owned expected-value-of-computation machinery.

PASS requires:
- no fixed class ordering;
- useful explanation receives evidence priority;
- wrong explanation loses authority through evidence;
- one factual stream remains shared;
- learned arbitration transfers to a new randomized mixture.

## Only then: INTEL-2

INTEL-2 must use new target worlds not used to author U1-U3.

One persistent organism, frozen cognitive code, no per-world module switching.

The verdict should again be all-or-nothing.

Do not resurrect G24/G25-style incremental claims as substitutes for system-level intelligence.

## Host boundary

Host may own only:
- raw I/O;
- serialization/persistence;
- deterministic audit;
- resource ceilings;
- Human Protection;
- test harness/world simulation.

Host must not own:
- reasoning mode priority;
- hypothesis priority;
- explore/exploit arbitration;
- attention allocation;
- representation-family selection;
- thought/action utility ranking.

## Scientific claim boundary

Passing U1-U3 would establish a stronger architecture-level claim:
carrier-owned meta-control over multiple acquired cognitive operations.

It would not by itself establish AGI.

Passing a later independently seeded INTEL-2 would be required for any renewed project-level claim of autonomous developing intelligence in a bounded world family.
