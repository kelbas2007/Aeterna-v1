# AETERNA-v1 — единый рабочий проект, 18 октября 2026

## Одна точка входа

`aeterna-v1` — основная программа. `aeterna-unified` — совместимое имя того же
исходного кода, не второй организм. Главный Cargo-запуск больше не подменяет
приложение старой демонстрацией мотора. Она сохранена отдельно:
`cargo run --locked --example legacy_motor_demo`.

```text
cargo run --locked -- --help
cargo run --locked -- --status
cargo run --locked -- --inspect learned-state.json
cargo run --locked -- --school learned-state.json
cargo run --locked -- --relations learned-state.json
cargo run --locked -- --jsonl
```

Статус перечисляет возможности кода, не наличие приобретённых знаний.
`--inspect` читает фактический checkpoint без записи, обучения и внешних действий.
Checkpoint необходимо предоставить явно. Независимые жизни не склеиваются;
старое состояние RSP1 не объявляется прошедшим допуск RSP2.

## Что соединено

ScientificRuntime владеет состоянием и внешними разрешениями. Конструкционный
Learner, EP1, школа/SG1, REL1 и RSP2 доступны через существующий runtime и один
JSONL-процесс. Консолидация не добавляет диспетчер вместо организма, не меняет
нейронные веса или критерии обучения. Программные вычисления не объявляются
спайковыми. Не все необязательные нейронные подсистемы совместимы одновременно.
Общий checkpoint не доказывает автономное использование каждого приобретённого
механизма: это остаётся отдельной исследовательской задачей.

## Review correction before consolidation

Generic native-only restart/restore APIs reject construction mode before any
mutation. Use the joint checkpoint API for a Learner/U1 state. Four regression
tests fail on the former source and pass with these three entry guards.
The RSP2 search algorithm and its admission rules remain byte-identical.
Two already-consumed DC-2 installers now have read-only manual verification
workflows; no current workflow applies those historical patches again.

## Центральный контур приобретения вычислений LC1

LC1 не самостоятельная ветвь интеллекта: он сохраняет выученные обратные
требования непосредственно в том же Learner и общем checkpoint, что RSP2/U1.
Публичный JSONL поддерживает enable_missing_computation_learning,
observe_executed_computations, complete_missing_computation и
missing_computation_report. Вычислительная цель и записи выполненных операций
служат источником; скрытые probes не передаются решателю. Без параметра
`sketch` система сама перебирает ограниченные гипотезы об отсутствующем
промежуточном выражении. С параметром `sketch` она достраивает конкретный
пробел. Любой предложенный ответ проверяется прямым исполнением VM.

RSP3 приобретает стратегию направления поиска; LC1 приобретает ограничения
для получения неизвестного фрагмента. Обе способности сосуществуют без
обхода RSP2 producer/admission. Это ограниченный программный эксперимент,
не доказанный автономный универсальный интеллект.

## Встроенный контур самостоятельного исследования (U1)

Теперь старый `Learner::choose_offered`, выбирающий неизвестное действие по
реальным PRE/POST и использующий найденную причинную зависимость для цели,
доступен как **кандидат** внутри основного U1 `ScientificRuntime`. Без явного
включения поведение не меняется; никакой отдельной сущности или прямой
власти над действиями не добавлено. Сохранение опыта происходит в общем
checkpoint, защита HumanProtection остаётся обязательной.

Честные локальные [метрики и ограничения](AUTONOMY_UNIFIED_EXPERIMENT.md):
24/24 перестановок ролей в синтетической среде (96 действий), paired 32-шаговый
контроль 22/24 против 19/24, восстановление другого процесса. Это НЕ AGI.
