# AETERNA-v1 — единый рабочий проект, 18 октября 2026

## Одна точка входа

`aeterna-v1` — основная программа. `aeterna-unified` — совместимое имя того же
исходного кода, не второй организм. Главный Cargo-запуск больше не подменяет
приложение старой демонстрацией мотора. Она сохранена отдельно:
`cargo run --locked --example legacy_motor_demo`.

```text
cargo run --locked -- --help
cargo run --locked -- --status
cargo run --locked -- --inspect learned-state.json
cargo run --locked -- --school learned-state.json
cargo run --locked -- --relations learned-state.json
cargo run --locked -- --jsonl
```

Статус перечисляет возможности кода, не наличие приобретённых знаний.
`--inspect` читает фактический checkpoint без записи, обучения и внешних действий.
Checkpoint необходимо предоставить явно. Независимые жизни не склеиваются;
старое состояние RSP1 не объявляется прошедшим допуск RSP2.

## Что соединено

ScientificRuntime владеет состоянием и внешними разрешениями. Конструкционный
Learner, EP1, школа/SG1, REL1 и RSP2 доступны через существующий runtime и один
JSONL-процесс. Консолидация не добавляет диспетчер вместо организма, не меняет
нейронные веса или критерии обучения. Программные вычисления не объявляются
спайковыми. Не все необязательные нейронные подсистемы совместимы одновременно.
Общий checkpoint не доказывает автономное использование каждого приобретённого
механизма: это остаётся отдельной исследовательской задачей.

допуск исправлен; устойчивое преимущество самоулучшения не установлено.
Протокол dual-role в истории — намерение исследования, не готовый результат.

Ранее ARC-AGI-3: 0/7; REL1: 224/1000 SVAMP и 134/1440 ASDiv-комплемента.
Исходные отчёты выше. Успешная сборка не меняет научных вердиктов.

## Ветки и проверки

`main` — опубликованный интегрированный источник для обычного использования.
`research/beyond-intel4` — будущая разработка; после слияния синхронизируется
с main. Временная integration-ветка не является альтернативной версией.
`intel4-frozen-unified` и `archive/evidence-20261008` сохраняются без изменения.
Локальный aeterna_genome_run этой работой не редактируется.

```text
python scripts/check_project.py
```

Единый активный workflow `regression.yml` проверяет Linux/Windows, RSP2,
школьные пути, защиту, общий checkpoint, совместимость двух имён и документацию.
Linux дополнительно выполняет прежние scripts/check.sh и scripts/demo.sh.
Специализированные дубли оставлены ручными; [каталог](PROJECT_STATE.json).
Исторические квалификации не возобновляются. Крупные сборки, toolchain и
локальные результаты не добавляются в Git. CI-пакеты имеют ограниченный срок,
а точный исходный код остаётся в истории. Новые изменения идут через PR.
