## Причинные маршруты при изменяющихся датчиках — новая исследовательская линия

Вместо предположения, что подготовительное действие обязательно
оставляет **все** датчики неизменными, отдельный холодный opt-in
`enable_constructing_observable_factual_routes` собирает граф
из только реально исполненных `PRE/мотор/POST` переходов.
Противоречащие данные для одинаковой пары PRE/мотор запрещают
переход; поиск ограничен глубиной 5 и бюджетом операций.
Только native U1 выбирает полный *временный* маршрут.
Каждый следующий физический шаг требует независимой защиты,
реального POST и отмены при несовпадении.

Первые два раскрытых эксперимента дали NEGATIVE
([без полезной обработки правдивого датчика](OBSERVABILITY_LIMIT1_RESULT.md),
[бесполезность старого строгого графового readout](OBSERVABILITY_LIMIT2_RESULT.md)).
После структурного исправления [результат](OBSERVABLE_GRAPH1_RESULT.md)
**194→457/864** и **296** реально завершённых приобретённых
маршрутов на Linux и Windows.
Второй датчик предоставлен виртуальной средой; алгоритм
поиска написан в Rust, не изобретён самой AETERNA.
Даже при этом пятишаговые задачи **20/288** остаются нерешённой
проблемой общего переноса. Новые исходники проходят ревью
[PR12](https://github.com/kelbas2007/Aeterna-v1/pull/12) до `main`.

## Состав организма и граница разрешений

Один `ScientificRuntime`: EvoPhase/U1 решает, какие варианты испытать;
`construction::Learner` приобретает причинные зависимости из фактически
исполненных PRE/action/POST; RSP2 проверяет поисковые политики на
сохранность/перенос; RSP3 и LC1 предлагают ограниченные новые вычисления;
School/SG1 и REL1 дают узкое приобретение символических знаний.
Одно совмещённое состояние сохраняется через
`checkpoint_constructing` и `from_constructing_checkpoint`.
Обычный бинарник — `aeterna-v1` (`aeterna-unified` — алиас).

Ни одно запланированное, воображаемое или вычисленное следствие не
считается физически выполненным. **Каждый мотор требует нового
HumanProtection permit**, реальной стоимости и настоящего POST.
Продолжение сохранённой опции немедленно отменяется при несовпадении
реального результата, изменении цели, перезапуске или недоступном моторе.

## Проверенный автономный цикл

```text
Цель (её задаёт среда)
 → выбор собственного действия/исследования U1
 → разрешение HumanProtection на одно действие
 → фактическое действие / PRE / POST / стоимость
 → каузальный журнал и предсказания Learner
 → гипотеза последовательности из собственной успешной истории
 → исходное решение U1 выбирает или отвергает целый option
 → каждое продолжение физически проверяется отдельно
 → итоговая награда исходному решению — только за реальный результат
 → Complexity Necessity Gate сохраняет простую модель
    либо исследует неопределённость / допускает более длинную историю
```

Этот цикл работает на описанных тестовых синтетических мирах. Длина
вариантов ограничена программной грамматикой 2–5, заданной человеком.
Критерий `0.03*(depth-3)` и выбор модели по реальным противоречиям
также заданы программно, а не изобретены организмом.

## Интерфейсы и реальная доступность

```bash
cargo run --locked -- --help
cargo run --locked -- --status
cargo run --locked -- --inspect path/to/checkpoint.json
cargo run --locked -- --jsonl
python scripts/check_project.py
python scripts/check_docs.py
python scripts/project_audit.py
```

`--status` — инвентаризация функциональности, а не интеллект текущего
пустого checkpoint. Стандартный JSONL `init` в
`src/bin/aeterna-unified.rs` устанавливает **planning_depth=2**,
хотя операции включения `enable_autobiographical_options`,
`enable_variable_depth_options`, `enable_complexity_need_gate`
уже существуют. Исторические 3–5-моторные результаты использовали
Rust `Config` с глубиной 3–5. Теперь `init` принимает явные
`planning_depth` до 32 и `planning_work`; значение по умолчанию осталось 2.
[Точная инструкция для JSONL](JSONL_AUTONOMOUS_OPTIONS.md).

Повторяемые инженерные тесты:
`cold_autobiographical_option_development`,
`cold_variable_depth_option_development`,
`complexity_necessity_development`.
Общий CI на проверенном source `dcaf9839` — [39374600877](https://github.com/kelbas2007/Aeterna-v1/actions/runs/39374600877)
(Linux и Windows PASS). One-use на каждом будущем пуше **SKIPPED** —
это не повтор scientific run.

## Следующий открытый рубеж

Не ещё один жёстко заданный макрооператор, а самостоятельный выбор
эксперимента, который отличает конкурирующие объяснения причинных
результатов. Далее нужны новые реальные независимые среды с объектами,
ресурсами, временем, стохастикой и доказанной сохранностью приобретённых
навыков. Нет доказательства AGI, универсального понимания языка,
автономного создания когнитивной грамматики и безопасной работы с
реальным оборудованием.
