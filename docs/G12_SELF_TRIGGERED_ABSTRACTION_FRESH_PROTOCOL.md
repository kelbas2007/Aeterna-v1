# FRESH-G12 — SELF-TRIGGERED PHYSICAL ABSTRACTION QUALIFICATION

Status: **PRE-REGISTERED BEFORE FRESH-G12 EVALUATOR/RUN**

Date: 2026-10-07

## Claim

Can one persistent Aeterna-v1 organism, across authority-sampled relation/motor/hierarchy assignments, refrain from allocating a higher abstraction while its acquired L1 concepts adequately explain factual outcomes, then autonomously recruit/promote physical L2 concepts only after supported factual evidence makes the L1 explanation insufficient?

This qualifies the bounded G12 self-trigger mechanism. It does not qualify arbitrary-depth open-ended abstraction or AGI.

## Generic relation pool

Use the same generic local two-pixel offset pool:

`[(1,0),(0,1),(1,1),(2,0),(0,2),(2,1),(1,2),(2,2)]`.

Per sub-seed:

1. randomly permute all eight offsets;
2. select one authority-random perfect matching of the eight atom positions as the four useful physical L1 target pairs;
3. select four other perfect matchings as balancing negative L1 experience;
4. randomly permute all four opaque motor IDs;
5. assign two motors to L1 foundation learning and the remaining two to the later top task.

No evaluator relation/concept/class label enters cognition.

## Fresh L1 acquisition

A single cold organism uses only the ordinary adaptive factual API:

`observe_phase_native_adaptive_concept_factual(raw_raster, opaque_action, factual_need)`.

For each of the four authority-selected L1 target pairs:

- four authority-selected absolute pair bindings;
- both foundation actions are physically/factually tried.

Four non-target perfect matchings provide one balancing exposure each at separate bindings.

Required before the top regime:

- exactly 8 acquired atom units;
- exactly 4 promoted physical L1 concepts;
- 0 recursive candidates.

## Authority-random adequate-child regime

Select one random perfect matching of the four L1 concepts as the **simple explanation partition**.

- the two concepts in one simple pair initially predict top action A;
- the two concepts in the other simple pair initially predict top action B.

Randomize:

- `single_repetitions` in **4..=6** per L1 concept;
- `simple_pair_repetitions` in **2..=3**.

Single-L1 scenes establish sufficiently supported individual physical evidence.

Then same-simple-class pair scenes are shown. FULL sees >=2 active L1 concepts but must allocate:

- **0 L2 candidates**;
- **0 L2 promoted concepts**.

A matched ALWAYS_ESCALATE diagnostic receives the same adequate-child experience and is permitted to allocate pair structure regardless of sufficiency.

## Authority-random residual regime

Choose two distinct perfect matchings of the four L1 concepts:

- one matching supplies residual class 0;
- the other supplies residual class 1.

This gives four pair types total and guarantees every L1 concept appears once under each residual class.

Randomize:

- residual cycle count in **24..=28**;
- pair presentation order independently for every cycle.

For every residual pair scene both top actions are factually tried.

The evaluator supplies **no** change flag, task phase, recursion request or abstraction level.

FULL must:

1. revise the existing L1 physical evidence;
2. detect supported weak L1 evidence from the physical pre/post factual state;
3. recruit a new physical L2 candidate only after that insufficiency exists;
4. keep an already legally recruited L2 candidate learning on later co-activations;
5. promote useful L2 concepts under the frozen support/joint-evidence/weak-child rules.

## Spatial layouts

Per sub-seed:

- pair bindings are authority-shuffled;
- four top-layouts are reserved for tuition/adequate/residual presentation;
- eight different top-layouts are reserved for held-out scoring;
- no held-out top layout is used in top-level tuition.

Each of the four residual pair types is scored on two held-out layouts.

Total FULL held-out N = **80**.

Learning is frozen before held-out scoring.

## Matched arms

1. **FULL_AUTO**
   - ordinary adaptive factual API;
   - auto abstraction enabled;
   - child revision enabled.

2. **NO_ESCALATION**
   - same state after adequate-child regime;
   - auto higher-level escalation disabled;
   - L1 factual revision remains enabled.

3. **FROZEN_SIMPLE**
   - same state after adequate-child regime;
   - child explanation revision disabled;
   - tests whether revising the old explanation is necessary to trigger abstraction.

4. **ZERO_PHASE_ESCALATION**
   - L1 and adequate-child state acquired normally;
   - phase learning set to zero before residual regime.

5. **ZERO_WEIGHT_ESCALATION**
   - L1 and adequate-child state acquired normally;
   - weight learning set to zero before residual regime.

6. **ALWAYS_ESCALATE**
   - same L1 start;
   - receives the same adequate-child experience;
   - recruits higher pair candidates whenever >=2 L1 concepts are active, independent of sufficiency;
   - structural-economy diagnostic only.

LEVEL1_ONLY may be reported diagnostically but is not a FRESH-G12 PASS gate.

## Fresh causal interventions

For each FULL sub-seed after frozen learning:

- choose the first generated residual pair;
- score its two held-out layouts intact;
- lesion one necessary physical L1->L2 synapse (weight 0) and score both layouts;
- independently shift the same learned synapse phase by pi and score both layouts;
- restore the exact saved synapse without retraining and score both layouts;
- lesion one L2 synapse belonging to another residual pair and score one target layout;
- lesion one atom->L1 synapse under the target hierarchy and score both target layouts.

Across the 10 sub-seeds this gives:

- 20 targeted lesion decisions;
- 20 targeted pi-phase decisions;
- 20 targeted restoration decisions;
- 10 unrelated-lesion decisions;
- 20 lower-layer lesion decisions.

## Interpretation boundary

PASS would establish statistical bounded **self-triggered abstraction escalation**: the organism can preserve a sufficient acquired explanation, revise it after contradictory facts, and allocate a higher physical concept level only when its own supported physical evidence says the lower explanation is inadequate.

PASS would still not establish:

- arbitrary-depth autonomous recursion;
- autonomous invention of primitive relation operators;
- unbounded structural economy;
- broad semantic concept learning;
- language;
- AGI or consciousness.
