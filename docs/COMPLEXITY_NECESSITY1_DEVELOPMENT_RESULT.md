## What determines that complication is needed?

The SAME existing protected Learner has three explanations for current
evidence. Its new **cold-only opt-in** chooses:

1. `retain_simpler`: an actual previously successful, still-consistent
   three-motor memory exists. Retain it; do not use novel deep history.
2. `investigate_insufficient_evidence`: no dependable simple route,
   but any deeper route lacks a real matched shorter-suffix failure or
   sufficient benefit to justify extra physical actions. No imagined
   success, no new action authority; existing U1 can still explore.
3. `extend_after_contradiction`: an actual protected goal success for
   the longer action history and a same-visible-PRE shorter-suffix
   failure yield an improved conditional goal prediction (Laplace
   estimate), exceeding the developer-authored simplicity tax
   `0.03*(depth-3)` per extra action. Only the native U1 decides
   whether to try the option. Full contradictory real replay withdraws
   its eligibility; each physical continuation still needs an
   independent HumanProtection permit, actual cost and real POST.

This is a **diagnostic decision about needed memory depth**, not autonomous
creation of arbitrary cognition modules or self-editing software.

## Why this is not general self-improvement

The trigger, Laplace success estimate, cost tax, and memory-depth cap of
5 were written by developers. The evidence comes from disclosed
deterministic worlds with a single visible numeric goal coordinate,
externally supplied goal and episode resets. **Only ONE five-action
sequence was successfully completed**, despite a 12-world five-action
family; broader five-action acquisition is unsolved.

The positive result does not show that EvoPhase autonomously
invented a new parameter, neural representation, sensor ontology,
program induction grammar or software architecture. It establishes
a small but causal **simplicity-first retention/admission improvement**.

**Next falsifiable barrier**: when simple-model residual uncertainty
persists despite failed causal-pair probes, let the organism identify
*which experiment* distinguishes two competing explanations, rather
than passively waiting for a rare five-motor success. After autonomous
discriminating tests work, reuse the same need/benefit/cost/retention
contract for memory variables, representational features and learned
subroutines. Keep `main` unchanged until external-world qualification.
