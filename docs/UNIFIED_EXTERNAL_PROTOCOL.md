# Unified vertical integration — development protocol, frozen before external play

The existing U1 phase-native readout chooses between acquired-model action proposals,
HDC recall, bounded model planning and directed construction inside ScientificRuntime.
The former construction-owned automatic schedule is disabled in this mode. Only the
ScientificRuntime protection boundary may invoke a real callback. This is a vertical
connection of existing mechanisms, not a claim that VM computations became spiking
neuronal computations or that every optional AETERNA lane is now active together.

## Teaching
An authored 32-channel/4-action virtual actuator environment is supplied. One channel
changes according to an unknown addition rule, other channels remain constant.
256 factual interactions; goals are authored during part of teaching, correct actions
and programs are never supplied. Freeze programs and U1 before testing 12 new larger
setpoints. Compare full controller, the identical acquired knowledge with zero U1
weights, and cold state. Keep all episode traces. No success threshold is tuned after
seeing the external ARC game.

## External trial
Official arc-agi toolkit 0.9.9, public game ls20, seed 0, at most 256 actual actions.
Game chosen before any solving attempt. Game source and solution examples are not read
by the agent/developer for this test; the official engine necessarily executes them.
Python supplies only rendered observations, available action IDs and actual outcome.
A separate Rust process chooses every action. No LLM calls or authored puzzle policy.

The sensor contract is 16 palette counts plus a 4x4 grid of integer color means.
This is lossy authored perception, not autonomous vision. Keep original frames in
JSONL to permit diagnosis. U1 state is retained from teaching. The numerical learner
is archived, and a new raster-grounded model is created; this does not claim transfer
of the numerical program to vision. No hidden-game or leaderboard qualification.
Report terminal state, completed levels, action count, checkpoints, and failed runs.
An executed run with zero completed levels is an unsuccessful external task attempt,
not a successful intelligence demonstration.

## Persistence scope and authority
Checkpoint carries the complete state of this cold-native+U1 construction mode,
not arbitrary combinations of all optional native lanes. Unsupported lanes fail
serialization explicitly. Real PRE commitments, programs and statistical debt are
kept. HumanProtection retains its monotone audit counter and emergency latch but
never serializes or reissues an outstanding permit. Restored cognition still needs
fresh external hazard screening. The shipped JSONL binary is for trusted virtual
adapters only; its fixed safe evidence is not valid for physical equipment.

The data-only hash detects accidental changes; it is not an authenticated signature.
No claim of anti-rollback against a privileged host. An external intent is flushed
before execution; an unknown result is never retried automatically. Branch stays
research/beyond-intel4. Main and frozen INTEL-4 remain untouched.
