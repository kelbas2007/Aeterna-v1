# ACTIVE-HISTORY-EXPERIMENT1 — active acquisition of causal history evidence

Date: 2026-10-20. Preregistration committed BEFORE implementation and
BEFORE any new evaluator outcome. Source parent: `3b8e8c2746b9feed886cba073ccab9e8c1ea8a48`.
This is a source-DISCLOSED engineering protocol, NOT new independent science.

## Why a new experiment is warranted

COMPLEXITY-NECESSITY1 admitted extra observed history ONLY when simpler
context fails. It improved 467→472/864 from an existing 2..5 grammar, but
in the five-action family only **7/288** episodes solved and **one**
five-motor option completed. Most attempts were classified as missing
evidence. A *decision that evidence is absent* is not yet an agent
that intentionally obtains useful missing evidence.

## Candidate mechanism: bounded contextual experiment selection

One **existing Learner** evaluates current actually executed PRE/action/POST
and the longest *consecutive same-sensor no-visible-effect suffix* of
past motor decisions since the most recent actual episode restart.
For each genuinely offered motor, estimate **how often** its
(context-suffix, candidate motor) transition has been physically tried
in the organism's own chronological protected records.

- An epistemic proposal targets the least-tested motor extension of
  the currently experienced opaque action history. Context depth is
  bounded by existing `planning_depth-1`, at most 4 predecessors;
  never infer hidden stage labels or teach the right motor.
- When no long suffix is present, use a minimal one-motor context.
  No journal insertions, imaginary postconditions or invented rewards.
  The nominated *one* primitive action competes with ordinary proposals
  under the existing native U1; do not invent a second action dispatcher.
- Exploration is enabled only in the opt-in
  `investigate_insufficient_evidence` branch of Complexity Necessity
  (shorter model unsupported, longer model not yet justified).
  Preserve known 3-motor solutions unchanged.
- The count is computed from actual id-adjacent, restart-safe
  PRE/action/POST rows; each computation is bounded by a fixed
  partition of the existing 6,000-unit probe-work budget.
- Quoted cost and available motors restrict the proposal.
  A chosen action still gets a fresh HumanProtection permit and
  a real external POST. Never award instrumental goal progress for
  "epistemic novelty" absent true measured goal effect.
- Persist a pre-experience enabled flag in the same checkpoint,
  with source binding and test coverage. Reuse existing action reports;
  optional telemetry may describe selection without granting authority.
- No changes to RSP2, phase-native synapses, HumanProtection or the
  one-use consumed scientific cohort.

## Frozen exposed evaluation

Use the same **36 disclosed worlds**, identical source-defined
starting conditions and matched opaque motor permutations, 24 episodes
per world, max 18 actual protected actions per episode. Compare:
  A) cold original complexity necessity gate,
  B) same gate + contextual epistemic experiment candidates.

Report for each family: REAL goal successes, real action cost,
native U1 choices of depth-experiment source, early vs late successes,
option depths and completed real goals, action traces and provenance.
Preserve all controls and negative outcomes. New tests must show:
  - direct-goal no hidden-dependency regression,
  - previous three-action family retained,
  - at least one actual native U1-selected contextual probe in the
    five-step worlds without external motor tuition,
  - no physical POST fabricated and joint checkpoint restored,
  - revoked/unavailable/safety blocked actions remain prohibited.

**Engineering target, not a presumption of success:**
at least one extra five-step goal vs the preregistered reference
(>7/288), no regression in direct and three-action families and
no >10% cost increase. If unmet, record NEGATIVE and do not retune
this disclosed set into "independent validation".

A future separately frozen source, seeded disjoint generator, stochastic
and externally owned world task will be required for scientific
cold-transfer qualification. This heuristic is a developer-authored
history-coverage strategy; it is not self-invented cognition or AGI.
