# FULL EVOPHASE OWNERSHIP CONTRACT

This file is normative for Aeterna-v1.

## Mandatory ownership

Adaptive cognition belongs to EvoPhase state. This includes learned sensory distinctions, representations, concepts, rival hypotheses, reusable skills/programs, composition, experiment selection, imagined rollouts, planning state, motor policy, factual revision and structural lifecycle.

Rust is the implementation language of the substrate and trusted shell. Rust may perform I/O, persistence, serialization, provenance checks, safety gates, bounded accounting and exact verification. It may implement generic EvoPhase physics and local plasticity. It must not hide task answers, a map, object labels, coordinates, a correct action, a hand-authored route or a task-specific symbolic solver.

## Authority firewall

REAL is written only by authenticated external observations.
MODEL and IMAGINED may influence hypotheses, planning and action selection but may never become factual memory without external POST.

## Required evidence chain

experience
→ EvoPhase state change
→ new prediction/concept/program/experiment/plan
→ changed action
→ factual external result
→ revision of the same EvoPhase-owned structure

A software object that never affects this chain is not an accepted cognitive capability.

## Matched controls

Ablations preserve the same raw observations, primitive substrate, resource limits and factual outcomes. They remove only the formation/readout under test.

## Development prohibition

A host-side result may be used as an oracle, verifier or diagnostic baseline. It cannot be counted as organism intelligence.
