Единственный runtime, отдельные права HumanProtection на каждый физический мотор, реальные POST, совместный checkpoint. Исходный RSP2 policy источник остаётся byte-identical. Разработка ограничена синтетическими детерминированными мирами; автор написал алгоритм выбора глубины памяти и порог штрафа, поэтому это **не** универсальное автономное структурное самоулучшение.

JSONL default `planning_depth=2`, поэтому 3–5 шагов требуют явной конфигурации Rust. Перенос на реальные сторонние среды, понимание свободного языка, устойчивое обучение пять-шаговым навыкам и AGI не доказаны.
