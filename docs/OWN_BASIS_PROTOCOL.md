# Own basis: заранее заданная проверка реализации

Требование: собственная обучаемая основа без предварительно обученных моделей.
Источники train/test: публичные Fashion-MNIST, UCI HAR, MNIST. Корпуса знакомы
проекту; новые наблюдения текущего запуска не являются слепым новым корпусом.

1. Два независимых организма начинают с необученного состояния. Единственное
   экспериментальное отличие — разрешение конструктивного роста. Ранее
   сохранённый ученик и сторонние веса не загружаются. Оба получают одинаковые
   явные уроки и предел 8 000 000 оценочных единиц работы на урок.
2. В каждом организме одна последовательная жизнь: Fashion → HAR → MNIST →
   возврат к каждому навыку. Имя навыка и соответствие классов моторам заданы
   явной инструкцией. Из названия корпуса, namespace или номера мотора не
   выводится правильный класс наблюдения.
3. На каждый навык: первые 3072 записи train, перестановка seed 20261022,
   256 последних записей официального test. Train/test не смешиваются.
   Параметры и исходник фиксируются до запуска test. Отладочный режим с
   другими размерами использует только отдельные train-записи и публикуется
   отдельно от этого измерения.
4. Test-метки используются только внешним счётчиком правильности. Сам организм
   не получает их ни как уроки, ни как награду. Все ответы исполняются через
   прежний защищённый U1, при равной стоимости доступных моторов.
5. После каждого навыка сохраняются checkpoint, прогнозы, расходы и допуски
   признаков. Происходит восстановление того же состояния. После следующего
   навыка прежние распределения должны совпасть побитово. Сохранение другой
   инструкции не выдаётся за удержание при переобучении той же инструкции.
6. Программа признаков допускается по 128 последующим разным учебным входам:
   минимум 5% уменьшения накопленного log-loss, без снижения числа правильных
   ответов. Текущая метка используется после обоих прогнозов. Вся работа
   неудачных кандидатов учитывается.
7. Публикуются ответы распознавателя и U1, расхождения, точность обоих целых
   организмов, число реально допущенных функций, использование чужих для
   текущего навыка функций, удержание и затраты. Главный эффект — изменение
   точности фактических ответов U1 относительно фиксированной основы.
   Ненулевые коэффициенты унаследованных функций показывают использование;
   преимущество переноса требует отдельного сравнения без их использования.
8. Журнал воспроизводится с проверкой каждого ожидаемого ответа транспорта,
   каждого фактического commit и идентичности конечного checkpoint.

Эта проверка определяет работоспособность собственной конструктивной основы
в общем организме. Она не является проверкой общего интеллекта, автономного
получения разметки или нового рекурсивного производителя RSP2.
