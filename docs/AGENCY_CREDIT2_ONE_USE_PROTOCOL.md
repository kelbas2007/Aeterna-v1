# AGENCY-CREDIT2 — preregistered fresh causal-role transfer trial

Date: 2026-10-19. Protocol freeze BEFORE test source or evaluation output.
Scientific status: one-use synthetic-world generalization experiment, **not AGI**. Research PR9 DRAFT, main unchanged.

## Hypothesis
On new external virtual worlds with hidden prerequisites, the SAME AETERNA factual experience with automatic agency-aware credit and short-history state inference can achieve better **actual protected multi-step goal outcomes** than the same learnt facts with the legacy U1 crediting rule. No manual turning policy learning off during identification is permitted in the experimental arm.

## Intervention and independent comparison
- Generate one exact real PRE/action/POST identification history in a disclosed elementary hidden-prerequisite source world, with an explicit forced motor availability mask. Every observation and actual physical action cost originates at ScientificRuntime's protected callback, not a synthetic fabricated journal.
- Rebuild two organisms with same initial U1, same factual identification world, same forced motor sequence and same real consequences. ONE change: whether opt-in agency-aware U1 credit is enabled before identification. No hand-written learnt programs, no U1 weights injected, no motor role names provided to U1.
- For each arm fork the acquired joint checkpoint. Freeze/retain identical factual learning policy across arms, activate identical short-history proposal capability, and let U1 freely choose among ALL permitted motors, with fresh hazard screening and actual external POST each step. Record first-action divergences, selected predictive-history steps, successes, actual action counts, per-family metrics.
- New challenge worlds use at least four source-disclosed causal families NEVER used in T-SR1, T-SR2 or earlier 24-role development. Their 4 opaque action IDs are randomly permuted according to the first unselectable GitHub Actions run ID, after exact source freeze; use ≥8 cases per family. Include a negative-control family where no hidden precondition exists.
- Worlds: (A) a single-use toggle latch where repeated arming toggles it OFF, (B) a short-lived readiness pulse consumed by any intervening motor, (C) a two-event temporal preparation counter NOT representable by a single-action history class, and (D) an unconditional-progress control. Note C is an intentional boundary stress, not expected to be solved.
- Max 24 actually executed external actions per trial. Executed actions are never chosen by the evaluator during qualification. Same initial world state, costs, goals and access masks in paired arms; no host correction or online retuning of thresholds.

## Precommitted scientific gate
1. Every arm and world remains inside the same HumanProtection single-use action authority; all POSTs are real evaluator outputs, no callback fault, checkpoint mismatch or non-repeatable acquisition.
2. The agency-aware arm must solve >= as many total trials, and must not lose successes in ANY family (including the negative control).
3. Agency-aware total action count must be <=90% of legacy arm (all unresolved trials charged 24 actions), and no increase in total external action costs.
4. At least one real **action choice divergence** must be observed, with at least one acquired short-history proposal actually SELECTED and executed in the agency-aware arm. A proposal merely offered is not credit.
5. The result must come from source unchanged after first trial. A tie, a missing selected history plan, regression in one family or a worse economy is **NEGATIVE** even if other families improve.

Do not select another seed, retry the same trial or optimize after its outcomes and call it unseen. Archive exact commit, GitHub merge SHA/run ID, seed, old/new success, action cost, selected history and full traces even if negative. Document when scientific protocol was preregistered.

## Limitations
Goal setpoints, allowed motors and physical reset routines are authored virtual evaluator facilities. Family dynamics are disclosed in trial source, so this is not a truly independent third-party POMDP benchmark. The candidate's prediction grammar handles only a ONE-action history suffix and cannot claim general hidden-state inference. Failure would be a useful limitation, not grounds to relax thresholds. The benchmark's extra family counteracts overfitting to the known 'prime then use' development fixture.
