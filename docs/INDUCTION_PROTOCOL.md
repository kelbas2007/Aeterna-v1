# Experience-built programs — contract before scoring

This open development experiment addresses the inherited Atom/AND/XOR menu in
G23. Its historical code and qualifications remain unchanged. The new opt-in
path uses generic conditional branching learned from factual vector/action/
outcome tuples; it never invokes G23's operator menu or circular rule templates.

The inherited learning algorithm partitions contradictory examples. It chooses
an input and a midpoint between observed values, then repeats within each
partition. Zero immediate information gain must not forbid a deeper interaction.
Inputs, thresholds, topology and leaf outcome strengths are acquired; bounded
branch/leaf primitives, the split search and selection policy remain software.
This is a broader learned program language, not invention without inductive bias
or qualification of complete physical ownership of the learning algorithm.

Fixed defaults: 15 physical nodes per motor, maximum depth 6, 128 factual tuples
per motor, two examples per child, eight subsequent checks per candidate and
two subsequent checks at the reached leaf. Any factual contradiction replaces
the candidate within its fixed pool and resets subsequent validation. Numerical
learning requires a full actual PRE and actual bounded external outcome. Leaf
coverage uses actual per-feature minima/maxima plus a fixed radius 0.15; a query
outside that coverage abstains. No unseen truth-table row is identifiable from
arbitrary Boolean data alone.

Primary engineering witness: all sixteen two-input Boolean functions, two fixed
motor/input permutations, four held-out numeric/distractor layouts per logical
row: 512 tasks. Training visits all logical rows with different numeric values.
Additional three-input parity, majority and selector functions: 192 tasks under
the same two permutations/four layouts. Goal: at least 95% correct per family,
with acquired measurement first, at most two actions and one terminal response.
These are new numeric observations, not unseen logical truth-table rows.
The host keeps the function and action semantics; EvoPhase chooses actual
actions and learns only their actual outcomes. Models are frozen at evaluation.

Controls see identical factual tuples: bounded prototype voting and a fitted
linear classifier. No superiority criterion is declared. Count tuition,
errors, abstentions and actions; do not relabel an unsuccessful family as PASS.

Required controls: no candidate before facts, subsequent-only promotion, no
imagined tuition, physical threshold/edge/response lesions and exact restoration,
unsupported-combination abstention, factual changed-law revision, fixed memory,
malformed topology rejection, atomic persistence and fresh observation after
restart. Run actual saved v7 files with the new reader. Exercise learn/run in
separate processes. Recheck the previous real-image task without enabling this
new program mode. Recorded-signal or general-purpose reasoning transfer is not
established by these synthetic Boolean witnesses.

## Open revision after first scoring

The initial greedy implementation passed all 512 two-input tasks, then failed
the first three-input parity variant: 16/32, sixteen abstentions. Evaluation
stopped there; the remaining three-input variants had not yet been scored.
This initial failure is preserved in the ledger and result.

The revised implementation scores complete recursively constructed programs,
with a fixed 2048-expansion search budget, rather than choosing a split solely
by immediate gain. Node limits, data, subsequent-check counts, primary 95%
criterion and evaluation action budgets are unchanged. A subsequent outcome
confirms a candidate only when its numerical estimate is within 0.1 of the
actual binary outcome; a correct sign alone is insufficient. The bounded fact
buffer preserves both outcome types; latest actual feedback for an identical
input replaces older conflicts, with aggregate discarded-conflict counts kept.
This last policy assumes deterministic outcomes and is not noisy calibration.

The matched prototype control is one-nearest-example with 32 retained successful
frames per motor. The linear control uses learned class centroids, whose squared
distance comparison is equivalent to linear scores with an intercept. Both learn
the observation-producing motor from the same actual POST masks and outcomes
and execute measurement then response within the same two-action budget.
