# Запуск проверенного примера AETERNA

Код `28030afd`, ветка `research/beyond-intel4`. Это исследовательский интерфейс
виртуального организма, не чат на человеческом языке.

## Готовая Windows-сборка

Артефакт `aeterna-unified-Windows-28030afd...` содержит:
`aeterna-unified.exe` — организм с JSONL-интерфейсом;
`unified-learning.exe` — выполненный пример обучения и проверок;
`trained.json` — настоящее приобретённое состояние после 256 событий;
`unified_arc3.py` — официальный внешний адаптер;
`PROTOCOL.md` — контракт и ограничения.

В PowerShell, из распакованной папки, пример обучения запускается без Rust и Python:

```powershell
.\unified-learning.exe .\trained-copy.json
```

Он заново обучит организм и напечатает JSON с полным сравнением. Достигнутый
результат проверенной версии — 12/12 целей; при тех же знаниях и обнулённом U1
6/12; холодная система 4/12. Имя нового checkpoint задаётся явно, чтобы не
перезаписывать приложенный исходный trained.json.

Запуск `aeterna-unified.exe` без адаптера ожидает JSONL-команды на stdin — это
не зависание. Использовать его с реальным оборудованием нельзя: приложенный
драйвер предназначен только для виртуальных безопасных сред.

## Из исходников

```text
cargo run --locked --example unified_learning -- trained.json
cargo test --locked --test unified_runtime
cargo build --locked --bin aeterna-unified
```

ARC-игра уже запускалась в CI: 129 действий, GAME_OVER, 0/7 уровней.
Установка toolkit и процедура воспроизведения находятся в
`.github/workflows/unified-external.yml`. Для ARC нужен Python 3.12 и официальный
пакет arc-agi 0.9.9 с предварительно загруженной игрой ls20-9607627b.
Новых запусков не следует выдавать за независимую квалификацию после знакомства
с опубликованным следом. Подробные результаты: UNIFIED_RUNTIME_RESULTS.md.
