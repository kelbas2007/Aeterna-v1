# SELF-OBJECT-1 — cold motor discovery from factual external effects

Date 2026-10-10. OPEN DEVELOPMENT, **not a source-frozen authority test**.

## Hypothesis
After the earlier staged/supervised FUNCTIONAL-CROSSWORLD-2 24/24,
can the SAME EvoPhase organism discover which opaque motor actually
changes a particular visual object, without a correct-motor demonstration,
persist this relation and reuse it in a *different Farama MiniGrid family*?

The native implementation is an opt-in PhaseGroundedObjects
self-experiment mode. It observes a generic *body-relative front tile*
of an already-specified regular tile sensor (7x7x3x4 bits). The caller
provides the egocentric sensor geometry but NO object identity, class
name, rule, chosen action or correct motor label. The organism
investigates least-tested opaque motors for the observed visual
category (not a pre-supplied motor schedule). Only after a real U1 +
Human Protection permitted PRE/action/POST locally moves or modifies
the front object's visible signature does a physically conducting
category→motor synapse acquire the positive action effect. Global
camera rotation is not admitted as a local object affordance.
Checkpoint and lesion/restore control are compulsory.

## First actual external attempt
Farama \`minigrid==3.1.0\` independently supplies task physics.
An *examiner*, not the organism, stages target objects exactly one
tile in front in the 10 new training seed sets 42000..42009.
This is necessary to isolate motor discovery from as yet unsolved
object navigation. **There is no tutor action or word lesson at all.**
The native organism gets ONLY its public 588-bit partial image and
actual protected action/post/reward. It must try motors itself.
Training: key in DoorKey-5x5, door in MultiRoom-N2-S4, maximum
ten actual external trials for each visually grounded category.

Cognitive state is checkpointed/restarted, model learning frozen,
then the same continuing organism encounters a new key in independent
MiniGrid-Unlock-v0 and an actionable locked door in DoorKey-5x5.
Examiner stages proximity, and for a locked door explicitly supplies
the matching carried key **without telling cognition**. 12 independent
heldout seeds 43000..43011 per task. The organism must choose its
acquired motor via U1 and the unchanged Human Protection gate.
Full-game task rewards are scored separately; an object interaction
is successful if actual external front tile visibly changes.

Predeclared OPEN development PASS: at least one actual action-induced
local effect independently acquired per object category, at least two
retained native affordances after checkpoint, 24/24 heldout actual
object transformations with no blocked/unsupported motors, and a
separate native no-tuition, synapse lesion/restore and frozen
execution test PASS. Log FAIL if any criterion is missed;
never relabel CI success as a cognitive PASS.

## Rigorous limits
Even a PASS is NOT independent autonomous DoorKey/Unlock completion:
the examiner stages both objects and a required key, and the
embodied front-tile geometry is provided. Its sensor already contains
categorical object codes; this is not raw RGB object segmentation or
unsupervised visual ontology discovery. The probing policy is a
hand-coded generic UCB-like least-tried Rust algorithm rather than
an algorithm invented by SNN. The result would prove only
**cold self-selected motor experimentation for a nearby
pre-categorized object and cross-family reuse of its real causal
action effect**, with no motor tuition. Navigation, object
permanence out of sight and autonomous prerequisites are still open.

It must not overwrite any previously consumed source/fresh seeds,
and a frozen independent scientific qualification requires a
separately pre-registered source and control suite.
