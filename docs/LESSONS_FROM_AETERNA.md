# Lessons carried forward from earlier AETERNA

These are empirical lessons, not inherited architecture.

1. **Model use is not model formation.** A planner using a learned row does not prove the organism learned the right representation.
2. **Memory access is not intelligence.** Retained RGB became available and changed probes without solving the task.
3. **Bigger memory is not a cure.** Several limits were representational/admission limits, not event-capacity limits.
4. **A new bank is not a concept.** The 126→79 ACT result showed useful representation plasticity, but no generalized Need program.
5. **Frozen transfer can hide adaptive search.** Transfer and learning-to-search must be tested separately.
6. **Host-owned cognition invalidates carrier ownership.** Exact Rust may verify, transport and guard; adaptive cognitive decisions must live in EvoPhase state.
7. **Counterexamples must remain.** A convenient law is not repaired by deleting contradictory factual evidence.
8. **UNKNOWN is a first-class result.** Missing input or unsupported extrapolation must not be filled with MODEL as REAL.
9. **Whole-organism cost matters.** Local elegance is not a capability unless downstream behavior improves at bounded cost.
10. **One causal chain per claim.** producer → acquired state → consumer → changed behavior → factual revision.
