## Что реализовано

В ScientificRuntime добавлен явно включаемый режим: существующий EvoPhase/U1
выбирает предложения действующей модели, HDC-воспоминания, ограниченное
планирование и конструирование. Прежний независимый автоматический запуск
конструирования Learner отключён только в этом режиме. Старые управляющие
входы ScientificRuntime блокируются, чтобы не было второго командующего.
Внешний callback вызывается только после проверки единой HumanProtection.

Сохраняются клетки/связи поддерживаемого U1-режима, приобретённые программы,
фактическая история, незавершённые пробы и статистический долг. Неподдерживаемые
комбинации других нейронных подсистем явно отвергаются при сохранении.
Это вертикальное соединение, не объединение всех необязательных механизмов
AETERNA и не доказательство AGI. VM-вычисления не объявляются спайковыми.

U1 использует пять предложенных признаков. Формула полезности, исследовательская
доля, лимиты внутренних операций и признаки заданы разработчиком; их значения
и физические веса меняются по реальному опыту. Произвольное самоизобретение
всего процесса мышления этой интеграцией не реализовано.

После загрузки сохраняются номер аудита и аварийная защёлка, не действующее
разрешение. Неизвестный результат внешнего вызова не повторяется автоматически.
JSONL binary предназначен для доверенных ВИРТУАЛЬНЫХ сред: его фиксированное
безопасное свидетельство нельзя использовать для физического оборудования.
Хеш состояния проверяет согласованность, не защищает от привилегированного
переписывания хостом всей истории.

## Выполненное обучение

Учебная среда — виртуальный числовой механизм: 32 наблюдения, четыре команды,
один изменяемый выход. Физика среды `x_next = x + action`. Организму эта модель
не выдавалась: существующий синтезатор приобрёл `Add(Action, Input(0))` из опыта.
Операция Add изначально входит в универсальную грамматику; это не изобретение
арифметики с нуля. Остальные выходы сохраняются без изменения.

256 реальных взаимодействий: первые 64 без цели, затем авторский набор малых
целей. Учебная последовательность целей подготовлена стендом; решения,
правильные действия и конструкторы не инжектируются. Приобретена одна модель,
270 обновлений U1. В обучении выбраны 4 вызова конструирования, 5 планирований,
5 обращений к памяти. Новых конструкторов и рекурсивных улучшений: **0**.

После заморозки программы и U1 даны 12 более далёких целей, максимум 6 команд
на каждую. Исходные знания и предел ресурсов в первом и втором вариантах
одинаковы; во втором обнулены только пять весов U1.

| Состояние | Целей достигнуто | Команд |
|---|---:|---:|
| Обученная система | 12/12 | 30 |
| Те же знания, веса U1 обнулены | 6/12 | 54 |
| Холодное состояние | 4/12 | 52 |

Пример новой цели на 7 единиц дальше текущего значения: команды `3 → 3 → 1`.
На всех 30 командах успешной проверки выбран источник `predict`, не `plan`.
Следовательно, показано последовательное применение приобретённого прогноза,
а не сложное дальновидное планирование. Это один небольшой разработческий
контраст, не независимый тест общей переносимости и не статистический вывод
о произвольных новых задачах. Эпизоды идут последовательно без сброса истории.

Обученное состояние загружено отдельным процессом `aeterna-unified`.
Checkpoint восстановлен побитово. На Windows и Linux совпали и результаты
обучения/проверки, и байты обученного состояния.

## Реальная внешняя попытка

Официальный toolkit `arc-agi==0.9.9`, игра `ls20-9607627b`, seed 0, максимум
256 действий. Выбор игры зафиксирован до первой попытки. Python передаёт
наблюдения и исполняет команды, все решения принимает Rust ScientificRuntime.
Правила и готовые решения не читались разработчиком политики/агентом;
официальный движок исполняет свой код. LLM-вызовов: 0. Использован локальный
режим после официальной загрузки; это не скрытая квалификация/leaderboard.

**129 действий → GAME_OVER → 0 из 7 уровней. Задача не решена.**
Новых установленных моделей: 0, конструкторов: 0. 91 действие выбрано через
воспоминание, 38 — через текущий прогноз. Модель осталась исходной.

Из числового обучения перенесены веса U1. Предыдущий Learner сохранён неизменным
в архиве домена, новая растровая модель начинается необученной. Это НЕ
подтверждает перенос числовой программы в визуальные задачи.

Представление изображения задано вручную: 16 количеств цветов и 16 средних
по сетке 4x4. Оно грубое, теряет пространственную информацию и не является
обученным объектным зрением. Планировщик требует явного вектора цели; в ARC
его не было, планирование не вызывалось. Этот опыт не устанавливает, какой
именно фактор был решающей причиной проигрыша.

FrameDataRaw.model_dump исключает пиксели. Логирование исправлено без изменения
политики. Повтор сохраняет прежние действия, наблюдения и решения:
`ab143985c9a6a7345518b42c6e583878596931f294fb7dbd2d155e724eaaa214`.
Проверены все 130 исходных кадров и 129 пар intent/post. Это воспроизводимость
