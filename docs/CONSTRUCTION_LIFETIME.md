# Единый автономный режим направленного конструирования

Это реализованный ограниченный программный цикл в `research/beyond-intel4`.
Он не переключает `main`, замороженный INTEL-4 и прежние режимы. Точный проверенный
коммит, результаты Linux/Windows и идентификаторы CI фиксируются в
`docs/evidence/CONSTRUCTION_LIFETIME_RESULTS.json`.

## Что запускается

Один `ProtectedConstructionRuntime` выполняет цикл:

**наблюдение → выбор разрешённого исследования → реальные PRE/POST → нерешённый
вопрос → расширяемый поиск программы и памяти → сохраняемая проверка → принятие
→ приобретение и применение конструкторов → следующее действие.**

Внешний адаптер не передаёт правильную программу, скрытое состояние, номер задачи
или расписание обучаемых выходов. Он объявляет наблюдения, доступность действий,
верхние оценки стоимости, сведения для защитного фильтра и фактические результаты.
Цель задаётся значениями выбранных наблюдаемых координат, не человеческой фразой.

`enable_autonomy(AutonomyPolicy)` атомарно фиксирует исследовательскую политику,
ресурсы и стохастический либо детерминированный контракт до первого опыта.
Отдельно включать EP1, curriculum и расширение квот больше не требуется.
В автономной жизни обходить предварительные квоты действий через старый
`step_action` запрещено. Прежний API сохранён для прежних режимов.

## Запуск

Windows:

```powershell
cargo build --locked --release --bin aeterna-construction
python scripts/construction_adapter_demo.py --binary target/release/aeterna-construction.exe --session artifacts/my-first-lifetime
```

На Linux имя бинарного файла — `target/release/aeterna-construction` без `.exe`.
Каталог должен быть новым: демонстрация не стирает прежнюю историю.
`rust-toolchain.toml` закрепляет Rust/Cargo 1.99.0. Python использует только
стандартную библиотеку; LLM API, платный хостинг и сетевой сервис не нужны.

Демонстрация запускает отдельный процесс Rust, предъявляет устройство с задержкой,
получает выбранные им команды и отправляет последствия. После 64 действий процесс
завершается; Python сохраняет состояние своей среды и подтверждает его при новом
запуске Rust. Обучение замораживается после 128 действий, исполнение продолжается
до 160. Это авторская проверка адаптера, не независимая квалификация интеллекта.

## JSONL-протокол другого внешнего адаптера

```
aeterna-construction SESSION_DIRECTORY
```

Программа пишет `ready` и имеющийся токен непрерывности. Один JSON-объект на строку,
не более 65 536 входных байт. Формы запросов есть в Python-адаптере.

| Команда | Содержание |
|---|---|
| `start` | Полные `config`, `policy`, исходное `observation`; только новая жизнь. |
| `resume` | Точный `continuity` и подтверждение продолжения среды доверенным хостом. |
| `step` | `offers`, `hazards`, необязательная частичная `goal`; действие выбирает runtime. |
| `post` | Ответ на текущий `act`: его `event`, `action`, реальные `observation`, `cost`. |
| `status` | Модель, опыт, незавершённая проверка и бюджет. |
| `freeze` | Необратимое прекращение обучения; исполнение и запись фактов продолжаются. |
| `rollback` | Возврат прежней программы без удаления опыта, расходов и долга EP1; запрещён после freeze. |
| `close` | Завершение после законченного взаимодействия. |

Промежуточный `act` содержит действие и номер события. Отсутствующий, неверно
нумерованный или несоответствующий ответ не становится свидетельством.
Неопределённое внешнее последствие блокирует дальнейшее исполнение.

## Изменения механизма

### Поиск по нерешённым вопросам

Следующий вопрос возникает из остаточной ошибки модели. Справедливый доступ
выходов не даёт большому шумному каналу вечный приоритет только из-за масштаба
значений. После неудачных законченных попыток растут размеры выражений, число
ячеек, очередь поиска и вычислительная квота до объявленного предела. Успешный
обучающий fit не считается завершённым приобретением. Защищённые выходы не
становятся кандидатами изменения.

Это написанная разработчиком метаполитика распределения ресурсов, не
самостоятельно синтезированный алгоритм управления обучением.

### Совместное создание памяти

Помимо однорегистрового поиска есть ограниченный поиск двух новых ячеек сразу.
Обновления строятся из обычных терминалов грамматики; допустимы синхронные ссылки
между ячейками. Бесполезная частичная память не устанавливается ради промежуточной
награды. Проверяется целая конструкция, которая может оказаться полезной лишь
совместно. Базовый поисковый резерв сохранён. Это не исчерпывающий поиск схем с
произвольным числом регистров.

### Конструкторы в непрерывной жизни

Исправлен дефект объединения опыта: успешные вычисления, полученные разными
путями поиска, раньше исключались из общего структурного обобщения. Теперь они
могут породить исполняемый конструктор, получающий поколение 1. Рекурсивное
происхождение по-прежнему требует двух успешных потомков одного реально
исполненного конструктора и воспроизводимого преобразования его кода.
Идентификатор конструктора не заменяет проверку происхождения.

Неудача на одной разработческой выборке понижает приоритет, а не навсегда
запрещает конструктор для всех последующих вопросов. Отрицательный результат
сохраняется. Сравнения с той же библиотекой и с предком конструктора остаются
отдельными от принятия модели мира. Рост числа конструкторов не объявляется
доказательством ускорения следующего обучения.

### Долговременное исполнение

`PersistentSession` хранит одну актуальную копию состояния, OS-lock одного
писателя и маленький маркер незавершённого внешнего действия. Маркер записывается
и синхронизируется до возможности внешнего эффекта. После сохранения нового
состояния он удаляется. Остался маркер после аварии — автоматического повтора
нет; требуется внешнее выяснение результата. Это намеренная безопасная
остановка, не гарантия exactly-once для произвольной чужой системы.

При восстановлении сохраняются опыт, стоимость, попытки EP1 и незавершённая
проверка. Старый аварийный запрет нельзя снять новым запуском. Прогнозы сверяются
с исполнением зафиксированных программ. Реальные разрешения не сериализуются:
каждое действие заново проходит прежнюю защиту EvoPhase.

Возобновляется программный learner, не всё SNN/синаптическое состояние организма.
Одинаковое наблюдение не доказывает одинаковое скрытое состояние мира: хост
отвечает за правдивое подтверждение непрерывности. Контрольная сумма не является
криптографической подписью против владельца хоста. На Unix синхронизируется также
каталог; на других платформах гарантии после потери питания зависят от ОС и ФС.

### Полномочия и затраты

Недоступное либо не помещающееся в бюджет действие не выполняется, включая
исследовательский резерв. Оценка цены не является физическим разрешением.
Фактическая цена выше обещанной записывается и останавливает исполнение до
принятия новых вычислений. Уже состоявшийся факт не стирается. Внешние полномочия
и защёлка аварийной остановки не расширены.

## Проверяемый результат и его границы

Семиканальный разработческий мир одновременно содержит четыре зависимости и
три мешающих канала. Он не переключает задания и не передаёт целевой индекс
обучаемого выхода. Проверяются три перестановки каналов/seed, по 3000 событий
обучения, затем 128 событий без обучения и отдельная наблюдаемая цель.

Все четыре зависимости проверяются на каждом новом событии: 4 × 128 × 3 = 1536
прогнозов. Ошибки трёх мешающих каналов также записаны; они не включаются в
утверждение о безошибочном предсказании изучаемых зависимостей. Модель, библиотека
и конструкторы после freeze не меняются. Каждый вариант — отдельная жизнь;
это не одна память, переносимая последовательно через все три перестановки.

В этом общем мире приобретены конструкторы первого поколения. Четыре поколения
рекурсивных конструкторов проверяются отдельным прежним стендом с заданной
последовательностью задач. Эти результаты нельзя объединять в утверждение о
четырёх поколениях полностью автономного развития во внешнем неизвестном мире.

Рабочий цикл, внешний протокол и долговременное исполнение соединены. Однако
реализация ограничена текущей грамматикой: до 32 целочисленных каналов, 16 действий,
8 ячеек состояния, журнал до 4096 событий, конечные метры и билеты доказательства.
По исчерпании квоты соответствующая работа останавливается, не удаляя историю
ради мнимого продолжения и не раздувая `artifacts` бесконечно. Примитивы VM —
целые, булевы, условные выражения, вызовы, ограниченный Fold и состояние; все
байтовые/последовательностные типы общей спецификации v0.1 не объявлены готовыми.

Естественный язык, произвольное зрение, открытое изобретение любого алгоритма
обучения и общий интеллект не являются результатами этого выпуска. Новая
система не названа SNN-прорывом: конструктивный поиск здесь программный.

## Проверки и отрицательные результаты

```text
cargo check --locked --all-targets
cargo test --locked --lib construction::
cargo test --locked --test directed_construction_unified
cargo test --locked --test directed_construction_session
cargo run --locked --release --example directed_construction_lifetime
cargo run --locked --release --example directed_construction_recursive
```

Новые тесты проверяют расширение поиска, совместную память, стоимость, сохранение
freeze, восстановление настоящего процесса, неправильный POST, аварийное
завершение после `act`, единственного писателя и сохранение отказов.

Пилот до исправления объединения конструкторов освоил простые зависимости,
но провалил составную во всех трёх вариантах. Попытка сократить обучение до
800 событий провалила два варианта. Эти результаты сохранены в
`docs/evidence/CONSTRUCTION_LIFETIME_PILOTS.json`. Они относятся к разработке,
не к скрытому holdout; никакой неудачный вариант не исключён. Возврат к исходному
бюджету 3000 не называется алгоритмическим прорывом.

Постоянный workflow имеет `contents: read`. Временные установочные файлы удалены
из итогового дерева. В Git не добавляются toolchain, vendor, target и живые
сеансы. Малые журналы CI ограничены сроком хранения 7 дней.
