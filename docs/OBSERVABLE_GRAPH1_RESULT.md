## EXACT matched cold study

36 pre-disclosed deterministic worlds, 24 episodes/world = **864
episodes per arm**, max 18 real protected physical motor actions per
episode, all 4 opaque motor channels available. Same goal mask
`[Some(1), None]`, same existing one U1/Learner, same policy/
complexity/context experiment capabilities, no forced training action,
no privileged motor-role labels. A new *actual* second sensor reports
true world preparation stage; BLIND arm receives constant zero.

Adding the empirical observable-state graph recovers **+263 solved
goals** over the actual richer-sensor incumbent (194→457) and
saves **3,959 real protected motor actions (−30.75%)**. The
original one-sensor U1 still leads total 487→457 (−30), so
restoration is substantial but incomplete. All **precommitted
ENGINEERING gates** passed (including ≥100 old 3-step and ≥100
four-step, at least 4 five-step, no direct-goal regression).
**ZERO world-level goal regressions** for rich-source control→graph.

The graph proposer never performs a physical motor. Its graph edges
are read from the organism's OWN chronological real PRE/motor/POST
journal and each exact PRE/motor pair with conflicting POSTs is
rejected; graph work is metered and bounded, and proposed routes
must be affordable. Only the existing native U1 can choose a route,
whose subordinate actions still require a fresh independent
HumanProtection permit and an actual matching physical POST. Only
a real reached terminal goal awards whole-option U1 credit. This
retains factual execution and version-1 checkpoint restoration.

No extra environment-defined motor scripts, labels or reward hints were
given to the learner. However, we **did** provide a true stage sensor
as an explicit external observation; this is not autonomous sensory
discovery or grounded natural-language understanding.

## WHY this is a meaningful boundary repair but NOT AGI

The previous historical option discovery required every preparation
to be **sensor-invisible across the full observation vector**.
Exposing legitimate, changing sensor state therefore killed it,
and the very conservative old certified chain method never
proposed an alternative. This experiment introduced an opt-in,
author-written empirical transition graph over observable full states,
supported by real physical transitions and tentative until each
new real POST verifies it. The causal relation is now usable even
when preparation is visible.

Remaining: only **20/288 five-step goals** solve with the true sensor,
and the new graph is still 30 goals short of BLIND overall. This is
not an independently generalizable achievement: the evaluators, motor
permutations and goals are all source-disclosed deterministic synthetic
tasks. An actual external sensor, noisy ambiguous observations,
real object identity, changing world dynamics, stochastic transitions,
sensor requests by the agent, and unbounded learned cognitive
representations are unqualified.

**Next test:** can the organism autonomously choose *which sensory
observation to request and pay for* to resolve conflicting partial
state hypotheses on independent externally owned worlds, instead
of requiring developers to provide the exact additional stage
coordinate? Preserve present protections, cost, retention and
actual counterexample tracking.
