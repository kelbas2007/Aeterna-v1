## Mechanism

Opt-in \`src/phase_factor_causality.rs\` receives no named features or
effect/precondition labels. It observes binary raw PRE/actions/POST,
finds altered sensory coordinates, stores reusable effect signatures
and guards, and tracks actual no-op contrasts. Each rule is enabled
by a real conducting native motor->rule phase synapse, retained in
the ordinary cognitive checkpoint and included in the learned
fingerprint. A bounded Rust BFS combines these factually learned
local effects into new IMAGINED joint states; readout passes a single
candidate to existing U1 and the unchanged Human Protection gate.
The runtime never inserts an evaluator-owned whole-state graph.
If there is no supported goal route it explores least-tested state/action
pairs and reachable novelty frontiers. No correct-motor curriculum is used.

## What remains unproven

**Important confound:** FACTOR-WORLD-1 and FACTOR-WORLD-2 use
DIFFERENT sensory structure. The original failed negative control used
24 arbitrary complete-state visual identities, including no raw
identifiable subfeatures. FACTOR-WORLD-2 exposes stable independent
binary visual channels at randomized pixel coordinates; invariants are
much easier to identify. It proves a narrow *raw-feature effect
composition* under favorable feature encoding, not perception-driven
discovery of object identities or fair measured superiority over the
old system on identical input.

Rule discovery, precondition selection, frontier search and BFS are
explicit Rust algorithms. No independent stochastic/topology-shifted
authority gate has been frozen. Binary no-op comparisons may be
confounded by unseen prerequisites; one-shot surprise recovery is not
full concept drift. Generalization to changing feature positions,
partial observability, real RGB object segmentation, multiple
resource amounts and robust long-horizon tasks is open.
