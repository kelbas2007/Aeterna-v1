## Единый организм

Каноническая программа `aeterna-v1` на Rust (без LLM), совместимый алиас `aeterna-unified`. Один `ScientificRuntime` хранит EvoPhase/U1, Learner, RSP2/RSP3, LC1, School/SG1, REL1, фактический PRE/action/POST журнал и checkpoint. Для каждого реального мотора требуется отдельное разрешение HumanProtection. Воображаемые или модельные результаты не считаются физически подтверждёнными.

## Как организм решает, когда усложнение нужно

Опциональный Complexity Necessity Gate выбирает `retain_simpler` (сохранить достаточную модель), `investigate_insufficient_evidence` (искать свидетельства) или `extend_after_contradiction` (расширить память только при реальном несовпадении с более короткой историей и подтверждённом выигрыше прогноза). Формула штрафа `0.03*(depth-3)` и верхний предел глубины **5** написаны разработчиком. Это не самосоздание когнитивных механизмов.

## Запуск и ограничения

```bash
cargo run --locked -- --help
cargo run --locked -- --status
cargo run --locked -- --jsonl
python scripts/check_project.py
python scripts/check_docs.py
python scripts/project_audit.py
```

`--status` перечисляет возможности бинарника, а не выученные знания. Обычный JSONL `init` имеет **planning_depth=2**; исследовательские результаты для 3–5 действий получены с явно заданным Rust `Config` для `ScientificRuntime`. Нельзя считать, что один JSONL-флаг уже запускает эти эксперименты. [Точный контракт интерфейса](JSONL_AUTONOMOUS_OPTIONS.md).

Сторонние независимые миры с изменяющимися объектами, ключами, ресурсами, стохастикой; универсальный человеческий язык; AGI; надёжное пятишаговое обучение; саморедактирование Rust/SNN — **не квалифицированы**.
