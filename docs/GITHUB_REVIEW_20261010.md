## Исправления по результатам проверки

- JSONL-адаптер внешнего агента ранее читал строку без ограничения размера.
  Теперь сообщение ограничено 64 KiB, превышение завершает протокол;
  оставшийся хвост не интерпретируется как новая команда. Добавлены проверки
  ограничения, обычных сообщений и фактического защищённого вызова действия.
- Общий CI раньше почти не проверял новые механизмы. В `scripts/check.sh`
  включены приобретение аргументов, физическая конкуренция, объекты,
  эпизодическая память, отношения и проверки внешнего адаптера. Точные
  селекторы отделяют импортированные тестовые фикстуры. Добавлены шесть
  существующих Python-проверок причинного оценщика.
- **28 уже выполненных диагностических workflows переведены в ручной запуск**.
  Их тела jobs, оценщики и assertions не изменены. Обычные pushes больше
  не запускают повторные оценки прежних внешних выборок. Основной CI
  продолжает проверять текущий код на main и research; отдельный архивный
  job проверяет прежний INTEL-4. Квалификации с использованными seeds не
  повторяются и не переименовываются в новые PASS.
- Обновлены README, каталог документации и текущие указания о main.
  Добавлены исключения для Python bytecode; исходники и научная история
  сохранены. Исторические прототипные patch-скрипты не входят в обычный запуск.
