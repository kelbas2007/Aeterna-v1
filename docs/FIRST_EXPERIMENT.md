# EVO-OWNERSHIP-0

## Цель

Минимально доказать причинную цепь:

raw observation → EvoPhase residual → structural recruitment → context-dependent prediction → changed motor choice → factual POST → revision.

Это precursor к полноценной raw-raster среде, а не ARC и не AGI-тест.

## Текущий минимальный мир

- 8 бинарных sensory channels;
- 2 opaque motor tokens;
- protected factual Need outcome;
- два контекста имеют общий anchor и различающий sensory component;
- held-out surface добавляет нерелевантный sensory bit;
- host не передаёт имя контекста или правильное действие.

GENUINE имеет structural growth.
NO_STRUCTURAL_GROWTH получает те же primitive cells, observations, outcomes и budgets, но dormant relays не могут рекрутироваться.

## Acceptance

1. REAL/MODEL/IMAGINED firewall не нарушен.
2. Residual рекрутирует carrier structure только в GENUINE.
3. На обеих held-out surfaces GENUINE выбирает правильный motor.
4. Control теряет contextual advantage.
5. Factual counterexample увеличивает revision **той же** recruited branch.
6. После независимой компиляции/тестов фиксируются exact source/commit и resource cost.

## Что этот gate не доказывает

Он не доказывает:
- самостоятельное выделение объектов из RGB;
- общий перенос отношений;
- program invention;
- planning;
- ARC/AGI.

Следующий этап после PASS — full raw raster PhaseWorld с тем же ownership contract, затем motif consolidation/program formation.
