# G3 — FIRST ACQUIRED REUSABLE EVOPHASE MACRO

Status: **PRE-REGISTERED BEFORE G3 IMPLEMENTATION**

Date: 2026-10-06

## Question

Can repeated successful carrier trajectories consolidate into a new persistent EvoPhase-owned macro-assembly whose body was not supplied by the developer, and can that macro be invoked on an unseen spatial binding to change physical action and produce factual success?

This is the first bounded acquired-program gate. It is intentionally smaller than a general programming language.

## Inherited substrate

Allowed:
- G1-B translation-invariant relational traces;
- generic HDC/FHRR binding and similarity;
- generic structural recruitment after repeated coactivation;
- opaque motor tokens;
- factual Need;
- fixed resource bounds.

Not allowed:
- a host-provided successful action sequence;
- a task-specific state machine;
- a Rust enum naming the learned strategy;
- hidden coordinates or object labels entering cognition;
- a hand-authored rule mapping intermediate scene to terminal action.

## Tuition world

Each episode is a two-action interaction.

The raw 12x12 start raster is the same relational pattern at varying absolute translations.

A hidden world context determines which relational intermediate raster follows the informative first action.

A factual Need is emitted only after the second action.

The successful policy therefore has a branching form:

```text
start relation
  -> opaque first motor
  -> observed relational intermediate A -> one terminal motor
  -> observed relational intermediate B -> a different terminal motor
```

The actual opaque motor numbers and relational branch prototypes are not supplied to the macro mechanism.

## Experience collection

G3 tests **consolidation**, not learned exploration; learned exploration remains G6.

Both GENUINE and NO_CONSOLIDATION receive the same fixed generic exploration curriculum:
- all two-action motor pairs are tried under both hidden contexts;
- every action and resulting raw raster is factual;
- only episodes ending in factual Need=true are eligible for consolidation;
- the curriculum does not tell the macro subsystem which sequence is successful.

The complete factual episode ledger is identical across arms.

## Carrier macro formation

The substrate records successful carrier dynamics as:
- translation-invariant PRE relational trace;
- first opaque motor coactivation;
- factual intermediate relational trace;
- second opaque motor coactivation;
- factual Need.

Generic structural plasticity may recruit a macro-assembly when repeated successful trajectories share:
- a matching PRE carrier trace;
- the same first motor;
- stable intermediate-trace -> second-motor branches;
- support >= the fixed promotion threshold.

The macro body is therefore acquired from repeated factual coactivation.

The first G3 implementation is deliberately bounded to a two-step branching macro. This bound is inherited substrate capacity, not a supplied task solution.

## Matched arms

GENUINE:
- macro formation ON;
- macro readout OFF during tuition.

NO_CONSOLIDATION:
- macro formation OFF;
- same factual episodes and all child representations.

Held-out:
- G_READOUT = GENUINE clone, learning frozen, macro readout ON;
- G_NO_READOUT = same acquired state, readout OFF;
- NO_CONSOLIDATION = same tuition facts, no macro.

## Held-out binding

Evaluation uses:
- start and intermediate rasters at absolute translations absent from tuition;
- the same underlying relational task;
- a two-action physical budget.

No held-out learning is allowed.

## Acceptance

PASS requires all:

1. Factual tuition episode ledgers are byte-for-byte equivalent across GENUINE and NO_CONSOLIDATION.
2. GENUINE acquires at least one macro; NO_CONSOLIDATION acquires zero.
3. The acquired macro stores the learned opaque first motor and at least two learned relational branches with different terminal motors.
4. The macro is absent before tuition and persists in the carrier state after promotion.
5. On both held-out hidden contexts, G_READOUT selects the learned first motor before receiving any held-out outcome.
6. After factual intermediate POST, the same macro selects the correct learned branch motor.
7. Both held-out episodes reach factual Need within the two-action budget.
8. G_NO_READOUT and/or NO_CONSOLIDATION fails at least one held-out episode under the same budget.
9. The held-out absolute translations were absent from tuition.
10. Previous G0/G1/G2 regression tests remain PASS.
11. Rust tests and release build PASS.
12. Tuition physical interaction cost is reported.

## Revision boundary

G3 does not close macro revision. G4 must present a factual counterexample that changes the **same acquired macro**, invalidates the old dependent branch prediction, and preserves the counterexample.

## Interpretation boundary

A G3 PASS would establish a first bounded acquired reusable control program as an EvoPhase macro-assembly. It would not establish:
- arbitrary-length program induction;
- recursion;
- Turing completeness;
- unrestricted concept invention;
- autonomous curriculum design;
- AGI.
