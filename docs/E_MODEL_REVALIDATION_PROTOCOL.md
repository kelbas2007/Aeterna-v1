## General bounded repair
When all of the following hold:
1. actual raw current/goal have valid acquired distinct abstract cells of same level;
2. a physical goal-value recurrence yields no path;
3. the usual unified cognitive proposal set is empty;
4. *every* local opaque motor already owns a supported physical transition at that abstract state;
5. planning/representation learning is enabled;

generate a single epistemic **revalidation** proposal from carrier-owned state/action evidence. Choose the locally least-supported modelled action, using a deterministic task-agnostic tie break, and assign a bounded epistemic pressure inversely proportional to factual support. Later confirmations increase support and reduce this pressure; contradictory POST enters existing factual revision. This is one native proposal competing under unchanged U1 meta-control, not a direct host motor authorization. Human Protection remains final.

Never use world IDs, motor answer labels, goal-known action, predicted change time, evaluator state, a fake POST or repeated episode reset. If safe action cannot be authorized, fail closed as before.
