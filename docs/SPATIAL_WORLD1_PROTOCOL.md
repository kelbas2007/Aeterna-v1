# SPATIAL-WORLD-1 — persistent egocentric-to-world memory and genuine long-horizon task benchmark

Date 2026-10-10, OPEN DEVELOPMENT, not prequalified AGI. Prior EMBODIED-WORLD-2 (run 38049301325) attained 7/16 full heldout tasks (4 Empty, 3 Unlock), 0/4 DoorKey and 0/4 MultiRoom, against 0/16 paired ablation and 1/16 random. These results are preserved.

## Proposed mechanism
Opt-in native `PhaseSpatialMemory` uses only real, public partial 7x7x3 categorical image bits plus executed protected opaque motor ID and actual post/action reward. By comparing geometric egocentric visual overlap under *left/right quarter-turn* and *one-cell forward translation* hypotheses, it learns physical motor motion categories and updates a bounded episode-local world-coordinate belief frame. It remembers observed landmarks, object category signatures, visited locations and empirically blocked/passable target cells. A fixed generic Rust shortest-path/visual-servo routine can select candidate exploration frontier, witnessed rewarded terminal appearance, or an affordance-bearing object. It routes that candidate as an ordinary U1 proposal; Human Protection executes actions. It never imports simulator position, compass, map, action names, task identity or route solutions. Native category→motor physical synapses continue to gate actually learned object actions. Navigation itself uses explicitly written Rust geometry and search, NOT intelligence spontaneously invented by the SNN.

A real positive task reward can establish a persistent learned appearance hypothesis for the goal tile from the factual PRE view, rather than from a host-provided goal marker. No privileged goal coordinate enters cognition. Unobserved surfaces remain unknown, map and current pose have explicitly bounded capacity and reset at each real episode; long-term motion rules and rewarded feature hypotheses persist through checkpoint.

Zero tutor motor labels, word lessons, stage object opportunities, prepared inventory, action meaning, internal simulator state, maps or mission strings. Independent evaluator alone may audit physical state to score key carrying, door opening, absolute agent position changes and task success; these audit fields are never passed to cognition.

Limitations: MiniGrid is an external SOFTWARE simulation with pre-categorized tile input, not raw RGB or physical robotics.
