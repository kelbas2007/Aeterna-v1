# Источники архитектурного обзора, 2026-10-21

Это сопровождение [обзора](../../BRAIN_ARCHITECTURE_REVIEW_20261021.md)
и [архитектурного решения](../../decisions/0001-learning-organism.md).
Новых результатов обучения или заявления об AGI здесь нет.

- `sources.json`: источники, Git blob и SHA-256, размеры, прочитанные разделы,
  исключения и границы доступа. 38 файлов не означают 38 изученных статей.
- `source-identity.json`: исходный `main`, хеши проверенных файлов и область
  анализа кода. Полный построчный аудит репозитория не заявляется.
- `sensor-information-witness.json`: две пары различных сырых наблюдений,
  фактически совпавшие внутренние кодировки, идентичность бинарника и
  сенсорного исходника. Один runtime, четыре подачи наблюдений, ноль внешних
  действий. Это свидетельство необратимого сжатия, а не benchmark качества.
- `reproduce_sensor_witness.py`: воспроизведение этого свойства через
  существующий JSONL API; исходники Rust не изменяются.
- `verification.json`: выполненные проверки ссылок, исходников, происхождения
  первичных текстов и точного воспроизведения свидетельства.

Полные сторонние статьи и учебник не копируются в проект. Неизменяемые
содержимые источников доступны через `immutable_content_api` в каталоге;
обычные ссылки на ветки служат для удобства чтения и могут обновляться.

Предыдущий эксперимент оценщиков завершён отдельно:
[результат](https://github.com/kelbas2007/Aeterna-v1/blob/02cd253b94e316521339db6d1d847560929fa2a7/docs/CAUSAL_READOUT_RESULT.md).
Его общий критерий не пройден; код исследовательской ветки не включается
в это архитектурное изменение.
