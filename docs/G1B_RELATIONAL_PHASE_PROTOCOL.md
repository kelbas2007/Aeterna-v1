# G1-B — RELATIONAL PHASE FORMATION FROM RAW RASTER

Status: **PRE-REGISTERED AFTER G1-A FAILURE AND BEFORE G1-B IMPLEMENTATION**

Date: 2026-10-06

## Why G1-A failed

G1-A used a repeated 3x3 local receptive field with shared slot roles. The first CI qualification compiled, but the learned motif set expanded too much on an unseen translation. The representation therefore remained too dependent on local patch alignment.

This failure is preserved in the experiment ledger. G1-B does not rewrite it.

## Scientific question

Can EvoPhase build a translation-invariant relational carrier trace from raw raster activity using only generic phase algebra and retinotopic position roles, then bind that acquired trace to factual action consequences and use it on unseen translations?

## Allowed inherited substrate

The carrier is allowed:
- a fixed retinotopic sheet;
- two generic HDC/FHRR axis role vectors;
- binding/unbinding and phase bundling;
- local factual outcome learning;
- structural recruitment;
- generic exploration pressure.

The carrier is not given:
- orientation labels;
- object labels;
- a horizontal/vertical detector;
- a list of relevant offsets;
- a correct action;
- a route or map.

## Representation mechanism

Each raster position has a carrier role generated compositionally from two generic phase bases.

For active pixels, the carrier forms pair-relations by unbinding one position role from another. A global translation contributes the same phase factor to both roles and therefore cancels under unbinding.

The carrier bundles all observed pair-relations into one MODEL-authority relational trace.

No host-side histogram of dx/dy values is constructed and no task-specific relation is selected.

## Acquisition

GENUINE:
- relation formation ON;
- relation readout OFF during acquisition.

NO_FORMATION:
- relation formation OFF;
- relation readout OFF.

Both arms:
- same initial carrier;
- same raw 12x12 rasters;
- same opaque motor policy during acquisition;
- same factual outcomes and resource limits.

The full acquisition action/outcome sequence must be identical.

## Held-out evaluation

After acquisition, learning is frozen.

G_READOUT:
- clone of GENUINE;
- acquired relation readout ON.

G_NO_READOUT:
- same acquired state;
- relation readout OFF.

NO_FORMATION:
- no acquired relation units.

Evaluation uses absolute raster translations absent from training.

## Acceptance

PASS requires:
1. acquisition factual tuples identical between GENUINE and NO_FORMATION;
2. GENUINE acquires relation units; NO_FORMATION acquires zero;
3. at least one identical acquired unit ID is active on a training scene and an unseen translation of the same private class;
4. G_READOUT chooses the evaluator-correct opaque motor on both preregistered held-out translations before outcome;
5. G_NO_READOUT and/or NO_FORMATION loses the complete held-out advantage;
6. REAL/MODEL/IMAGINED firewall remains intact;
7. compile, all tests and release build PASS;
8. no host-side class label, orientation label, dx/dy classifier or correct-action table enters cognition.

## Interpretation boundary

A PASS would establish one narrow result: EvoPhase can form and reuse a translation-invariant relational distinction directly from a raw raster under a fixed retinotopic phase algebra.

It would not establish:
- arbitrary object discovery;
- arbitrary relation invention;
- program invention;
- planning;
- ARC competence;
- AGI.
