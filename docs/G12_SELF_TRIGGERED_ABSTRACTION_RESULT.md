## Architectural meaning

The FULL path receives only:

- raw raster;
- executed opaque action;
- factual Need.

It does not receive a task-phase label or an explicit recursive-tuition call.

The same organism:

1. acquires physical L1 concepts;
2. sees a regime in which they adequately explain top actions;
3. allocates **zero** L2 structures;
4. receives later contradictory/balancing facts without a change flag;
5. detects supported but weak child evidence;
6. recruits L2 physical candidates only after that insufficiency appears;
7. promotes useful L2 concepts;
8. uses them on held-out scenes.

The fix that closed the final mechanism gap is prediction-error ordering: explanatory sufficiency is measured from the physical child state before the current factual update can erase the residual, while child learning still receives that same factual result.
