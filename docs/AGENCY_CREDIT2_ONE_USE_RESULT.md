## What was causally changed

Each arm acquired exactly **133 real, HumanProtection-authorized PRE/action/POST** transitions, with an IDENTICAL forced action/observation history from the same disclosed hidden-prerequisite identification world. The test compared every recorded input/action/output observation in both arms. Neither arm received a ready-bit sensor, a motor role label, a prescripted target action during evaluation, or a manually installed evaluator.

The legacy arm trained native U1 meta-action weights on every forced identification motor. The new opt-in agency-aware arm **suppressed only native U1 choice credit when there was no choice**, while preserving all real factual learning. After acquiring experience, BOTH arms enabled the same one-history factual proposal mechanism and had all ongoing learning frozen. Virtual evaluation trials started from each arm's saved cognitive state and had the same hidden world, goal, available motors, action cost and time budget. Only U1's acquired choice weights differed.

## Critically important limitations

1. This is a synthetic, research-authored world generator; each family's transition logic was source-disclosed before its first run, and the run ID selected motor permutations. It is a clean one-use *developmental* transfer challenge, NOT a genuinely independent external platform.
2. The causal history reconstruction is still one executed motor deep. Performance in the two-preparation family may partly come from exploration and different U1 weights rather than a learned two-stage hidden belief; it is NOT proof that a two-step latent counter was recovered.
3. Suppressing inappropriate native choice credit was **designed and implemented by the developer/assistant**. It is not evidence that the organism independently invented this correction. The acquired histories and native U1 proposals are organism-side; the algorithmic intervention is authored.
4. Both arms acquired knowledge from an externally scheduled identification episode (valid real action observations, but not autonomous discovery from cold start). The future active-learning agenda must remove this teacher schedule and choose tests by information value.
5. A positive 32-case synthetic outcome is not sufficient to merge a general-intelligence claim, relax HumanProtection, or infer future improvement in unrelated environments. The original negative T-SR1/T-SR2 runs remain negative and unchanged.

## Next decisive barrier

Without manually telling the organism when it has a choice, AGENCY-CREDIT1 already makes the distinction. The next *genuine autonomous* step is to let the same organism **select its own information-gathering experiments**, learn why zero-progress preparation matters without forced-motor tuition, and then produce robust multi-step plans when motor meanings and hidden causal structures are newly permuted. The next assessment needs an external, independent simulator and clearly separated cold discovery versus previously trained transfer.
