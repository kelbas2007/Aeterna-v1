# R1 / G1-C — ROBUST CARRIER-OWNED RELATIONAL PERCEPTION

Status: **PRE-REGISTERED BEFORE IMPLEMENTATION**

Date: 2026-10-06

## Why this gate exists

The first G7 one-use fresh qualification failed at 20/80. Every one of the four
nuisance categories scored 0/20 while the two clean worlds in every sub-seed
survived. Downstream exploration, hierarchy and same-identity revision still
showed causal advantages on survivable cases.

R1 therefore changes perception only. It must not add a task solver.

## Claim

A generic EvoPhase perceptual substrate can represent sparse raw raster
relations in a way that preserves learned task-relevant identity across
translation, 90-degree rotation, uniform scale, one irrelevant added point and
one missing point, without receiving nuisance labels or a correct-action label
at readout time.

This is a bounded perceptual mechanism claim, not an AGI claim.

## Permitted substrate primitive

R1 may add a parallel robust relational channel inside the carrier.

The channel may:
- enumerate local triples of active sensory positions;
- encode only relations intrinsic to that triple;
- use squared inter-point distances and a common-factor reduction so the atom is
  invariant to translation, rigid rotation/reflection and uniform integer scale;
- bind the resulting generic relation atom into the existing HDC/FHRR carrier;
- retain multiple atoms from one scene;
- compare two robust traces by carrier-owned atom overlap/containment.

The directed pairwise phase trace remains available in parallel. Robust
invariant atoms are opt-in at the raster-field configuration level so tasks in
which orientation is semantically relevant keep the directed channel.

## Forbidden shortcuts

Production cognition must not:
- receive nuisance type flags;
- branch on rotate/scale/dropout/distractor labels;
- rotate, resize, crop or otherwise canonicalize a whole evaluator image using
  hidden task knowledge;
- inspect world-family IDs;
- inspect the correct motor;
- call an external model, network service, OpenCV-style object detector or LLM;
- contain lookup tables for R1 test shapes.

The evaluator may generate nuisance views but may pass only the resulting raw
12x12 numeric raster to EvoPhase.

## Learning boundary

The invariant relation algebra is an inherited perceptual prior, analogous to
the existing translation-cancelling phase algebra.

Task meaning is not inherited:
- action/outcome associations remain learned only from factual episodes;
- no invariant atom contains a motor ID, class label or reward;
- learned readout can be ablated independently.

## Development witness

Before any new G7 fresh authority is consumed, a deterministic non-fresh R1
mechanism test must use:
- at least four non-congruent sparse shape families;
- opaque motor assignment;
- clean tuition only, at translations disjoint from evaluation;
- all opaque motors factually tried in tuition;
- learning frozen before evaluation;
- held-out clean plus translation, rotation, scale, one-point addition and
  one-point deletion views.

The robust arm and controls receive identical factual tuition.

## Controls

1. **ROBUST_CARRIER**
   - robust atom formation/readout enabled.

2. **DIRECTED_ONLY**
   - same EvoPhase and factual tuition;
   - old directed pairwise relational trace only.

3. **NO_ROBUST_FORMATION**
   - robust readout path exists but no robust atom state may be acquired.

4. **NO_READOUT**
   - acquired robust state is present but cannot influence action.

## Mechanism acceptance

R1 mechanism PASS requires all:
- clean held-out accuracy is not lower than 90%;
- each nuisance category has non-zero success;
- aggregate nuisance accuracy is at least 80%;
- ROBUST_CARRIER strictly exceeds DIRECTED_ONLY on aggregate nuisance accuracy;
- removing robust formation or readout removes a material part of the advantage;
- motor assignment is acquired from factual outcomes, not encoded in invariant atoms;
- G0-G6 regressions remain PASS;
- ownership audit remains PASS;
- release build passes.

The fixed development witness is not statistical qualification and must never
be cited as fresh evidence.

## Integration requirement before G7 retry

After R1 mechanism PASS:
- the same carrier trace type must be usable by epistemic hypotheses, macro
  entry/branch matching and hierarchy cues;
- G7 clean preflight must remain PASS;
- a deterministic nuisance preflight must show the full chain can traverse at
  least one case in every nuisance category;
- only then may a new G7 one-use fresh authority seed be consumed.

The failed G7 packs with digests `8aee63cd272b8536` and
`20dced638bb44450` remain burned and may be used only for diagnosis/regression.
