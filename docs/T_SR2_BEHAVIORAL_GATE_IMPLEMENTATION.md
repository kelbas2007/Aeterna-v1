# T-SR2: behavior-first gate in existing ScientificRuntime

Date: 2026-10-19. **Engineering research, opt-in; not a qualified intelligence result.**

A behavior-first switch must be enabled immediately after the existing
trajectory self-revision lane and BEFORE acquiring episodes:

- enable_constructing_trajectory_self_revision()
- enable_constructing_behavioral_gate()

When subsequent real PRE/action/POST trajectories lead to a VM expression
that passes the predictive shadow gate, it remains ineligible to alter
ordinary U1 action valuation. A future evaluator challenge can call
qualify_constructing_behavioral_gate(tasks, hazard, execute) on the same
ScientificRuntime. This method constructs two frozen cognition twins per
task from the *same byte-identical* checkpoint, with the learned readout
disabled only in the incumbent arm and enabled only in the candidate
sandbox arm. Both issue genuine protected action requests, consuming
fresh callback hazard evidence and real external POSTs.

The cognitive runtime never sees task cohort labels, hidden transition
roles or success labels. A bounded audit records chosen actions, observed
posts, action costs and first-action scores. Recomputed results require
no drop in task success in any evaluator-declared cohort, no greater
external cost, >=10% fewer total actions and divergent actual first
decisions. Failure (including aborted callbacks) consumes the one-use
trial; no silent retry can be used to cherry-pick pass outcomes.

A candidate is deployed only if the resultant audit qualifies. Prior
opt-in trajectory research not enabling this additional behavioral gate
remains unchanged, for historical comparison. The VM cannot access
actuator authority, modify RSP2 admission, forge POSTs or change the
HumanProtection evidence screening process.

**Limits:** This is a paired *virtual-environment* sibling experiment,
with evaluator-owned resets; it is NOT necessarily a safe or reproducible
physical-world A/B test. Cohort labels and virtual world outcomes are
host-side declarations: the engine checks the proof's internal
consistency, but cannot independently authenticate the outside world.
The gate can only compare actual chosen actions in the paired runs;
unexecuted counterfactual predictions confer no credit.
The comparison cannot prove generalization to environments beyond the
specified cohorts. A clean test suite is engineering integrity, not
scientific qualification.

See precommitted T_SR2_BEHAVIORAL_GATE_PROTOCOL.md. Earlier T-SR1
negative result is retained and may not be used as new qualification.
