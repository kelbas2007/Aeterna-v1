Итого девять Python-регрессий и девять целевых проверок наградной памяти. Новая сводка — count-min таблица из 4×2048 чисел f64, 65536 байт. Совпадения хешей могут завышать массу неудач, поэтому это консервативная оценка, не точная бесконечная история. При повторном вытеснении записываются только новые неудачи, уже учтённый prior не дублируется. Новые поля опциональны при загрузке старого checkpoint; утраченные старым кодом факты не восстанавливаются из ничего.

Исправленный Rust проверяется инженерными регрессиями и новым CI. Внешняя точность исправленного алгоритма не измерена; будущая оценка требует свежих данных. RSP2 и исторические источники C4 не менялись.
