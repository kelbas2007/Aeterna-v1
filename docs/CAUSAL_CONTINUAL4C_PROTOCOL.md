# CAUSAL-CONTINUAL-4C — протокол до оценки

Цель — проверить всю исправленную реализацию после ревью, включая одинаковое
применение оставшегося срока во всех планировщиках. Это инженерное сравнение
на известных авторских семействах с новыми перестановками; не независимая
внешняя квалификация интеллекта и не выделение единственного механизма.

До первого обращения к мирам фиксируются чистый commit, release-бинарник,
его SHA256 и данный протокол. После начала оценки исходники не меняются.
Диапазон C: **250000..250031**, ровно 32 мира. Ни один seed C ранее не
использовался для настройки. B 240000..240031 и первоначальные отрицательные
230000..230031 считаются использованными и не подменяют C.

Тот же открытый оценщик и те же верхние физические бюджеты: четыре семейства
(`ten_step`, `noisy_sensor`, `uninformative_sensor`, `direct_goal`), три варианта
(`legacy`, `causal`, `horizon_one`), всего **384 полные жизни**. Каждый вариант
учится с нуля, замораживается и восстанавливается перед проверкой. Адаптер
сообщает всем одинаковый смысл оставшихся действий; все планировщики его
соблюдают. Реальный расход действий и измерений может различаться и публикуется.

Пять заранее заданных порогов:

1. Причинный вариант решает не меньше 24 из 32 десятишаговых целей.
2. Его результат на этих целях выше варианта с горизонтом один.
3. На полезном шумном датчике он достигает не меньше 75% целей.
4. Там же превосходит старый вариант не меньше чем на 10 процентных пунктов.
5. На простой цели уступает старому варианту не больше чем на 2 процентных пункта.

Полные PRE/действие/POST/стоимость/срок сохраняются для всех вариантов,
включая неудачи. После раскрытия результатов диапазон не переиспользуется
как свежий. Прогон продолжается до всех 384 жизней; ошибка исполнения даёт
неполный отрицательный результат с сохранением имеющихся траекторий.
Повтор после исправления требует другого диапазона и отдельного протокола.

Команда после фиксации исходников и release-сборки:

```sh
python scripts/run_causal_continual4.py --binary target/release/examples/causal_continual_eval --first 250000 --workers 4 --output /workspace/.aeterna-env/causal4c-frozen
```

Проверки защиты, сжатия сложного состояния, наград и ограничений срока
являются отдельными повторяемыми регрессиями; они не считаются новыми
отложенными мирами. Успех C не доказывает перенос на произвольные реальные
данные, освоение маршрута исключительно из нулевого старта или неограниченную память.
