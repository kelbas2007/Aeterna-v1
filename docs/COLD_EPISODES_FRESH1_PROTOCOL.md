# COLD-EPISODES-FRESH1 — first one-use disjoint causal-family challenge

Date: 2026-10-19. **Preregistered BEFORE authoring the new world source and BEFORE the one-use Actions run.** This is a synthetic, source-disclosed research transfer check, not an independent third-party POMDP evaluation or AGI claim.

## Claim
One persistent AETERNA organism learning via *only its own freely selected, protected, actually executed actions* plus verified external episode observations improves task completion/economy across unfamiliar causal structures when the opt-in predictive one-step history and epistemic pair probes are enabled. Do not conflate this with independent invention of the algorithm: both abilities were developer-authored.

## Arms and fixed runtime
- BASELINE: cold ScientificRuntime with the existing agency-aware credit and self-directed factual Learner; no predictive-history/probe opt-ins.
- CANDIDATE: identical cold initial runtime, agency-aware credit, self-directed factual Learner, one-step predictive-history and native U1 selectable causal pair probes. No experimental goal-only instrumental credit; that branch was negative in open development and is not a candidate.
- Native U1 learning enabled for both; initial goal-value weights, resource limits, architecture, sensors and motor counts identical. **All four motors always offered at every step**. Goal is externally specified `progress >= 1` in each episode. No forced training actions, teacher demonstrations, resets expressed as selected motors, synthetic PRE/POSTs or hidden-state labels inside the organism.
- A new trusted WORLD episode observation is emitted by the environment only between completed/expired trials using the frozen joint restart API. The same cognitive journal and U1 weights continue; only actual sensory state is refreshed, and chronological history cannot leak across the restart.

## Disjoint evaluator-only world families
32 paired cases, **four new causal-transition families** × eight externally seeded distinct opaque motor maps each. Their sources are frozen before trial and not optimized on first result.
1. A target motor works only after a *mode-choice motor* sets a hidden binary mode; the other mode-choice motor changes the mode. The mode is not a separately observed sensor.
2. An ordered three-action prerequisite with two distinct preparations and an executed final-use motor. The one-step suffix is not necessarily a sufficient memory.
3. A time-window prerequisite that expires unless a physically executed bridging action takes place before the goal motor. Intentional non-Markov/delayed-state stress.
4. Negative control with one unconditional goal motor and other neutral/reset motors, no hidden preparation dependence.

The exact permutation in each case is determined solely by the first **unselectable GitHub Actions run ID** after source freeze. No version selection after seeing outcomes. A different causal pattern from the exposed COLD-EPISODES1, T-SR1, T-SR2 and AGENCY-CREDIT2 families is required; simply shuffling roles in the old ready-bit world would not qualify.

## Actual execution
Every one of the 64 organism/case combinations begins fully cold, performs **24 consecutive environment episodes** with up to **18 physically permitted, actually executed actions per episode**. The evaluator records goal successes, all action counts, native source choice, selected epistemic probes, selected learned history plans, early 6 vs late 6 episode success and protection/audit integrity. Goal success is assessed from the REAL observed terminal state, not a caller-provided label. Failed episodes count all actually executed attempts (18 if no goal), not fake successful paths.

## Falsifiable one-use success threshold
All of these must hold:
1. Candidate total solved tasks (out of 768) >= baseline, and per-family successes never regress; no control-family failure introduced.
2. Candidate total actually executed actions <=90% of baseline, with no larger total external cost.
3. At least ONE causal probe and ONE later history goal proposal were actually selected/executed by native U1 in the candidate group; merely being offered is insufficient.
4. The candidate's **late-six episode success rate** aggregated across cohorts exceeds its first-six success rate, and no protection, source binding, checkpoint or restart chronology violations occur.
5. Exact source/head/merge SHA, run/seed, family summaries, all real action and episode traces, code revisions and any missing evidence must be archived even when a test fails.

If any condition fails, status is **NEGATIVE / NOT QUALIFIED**, regardless of aggregate successes. No post-trial parameter tweaks or retries on the exposed run may be relabeled as fresh. A passing result remains a *source-disclosed synthetic cold-adaptation result*, not open-world AGI or independently invented self-improvement.
