## Per-sub-seed generation

### Raw relation assignment

Start from the frozen generic local relation pool:

`[(1,0),(0,1),(1,1),(2,0),(0,2),(2,1),(1,2),(2,2)]`.

Authority shuffles the eight offsets before assigning temporary atom positions 0..7.

### Level-1 target matching

Use a fixed generic 1-factorization of eight positions containing seven disjoint perfect matchings.

Authority chooses one matching as the four target level-1 concepts.

Choose four other factorization rounds as negative balancing matchings. No negative edge may equal a target edge.

Target pairs receive four factual absolute-binding scenes; every negative edge receives one factual scene.

This preserves the G11 weak-child condition while making the actual level-1 pair identities fresh.

### Opaque motors

Authority permutes all four physical motor IDs.

- two become foundation motor channels;
- the other two become top-level motor channels;
- which motor is positive/negative within each pair is authority-derived.

No motor semantics enter cognition.

### Level-2 assignment

The four acquired target level-1 concepts are indexed only by their acquired child relations.

Authority chooses two distinct perfect matchings of the four level-1 concept positions:

- first matching = top class 0;
- second matching = top class 1.

Every level-1 concept therefore appears once in each top class and remains individually non-predictive.

### Spatial layouts

Use authority-shuffled tuition and held-out banks of four-motif absolute layouts.

- Stage-1 target tuition: 4 bindings per target pair;
- Stage-2 tuition: 4 layouts per top pair;
- held-out: 2 layouts per top pair, absent from tuition.

Thus each sub-seed has 8 scored top-level held-out decisions.

Total FULL N = **80**.
