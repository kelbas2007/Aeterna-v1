# Обучение AETERNA по примерам: выполнено; человеческий уровень не достигнут

Проверенный исходный код: `a0c7db1dbe3f8e6ba5655deeb22793e00cb94c34`.
Ветка: `research/beyond-intel4`. Основная и замороженная INTEL-4 ветки не менялись.

## Реализация

В существующий ScientificRuntime добавлен сохраняемый образовательный слой.
Он принимает вопрос/ответ учителя, выделяет целочисленные аргументы и ищет
исполняемое выражение в ограниченной универсальной грамматике VM. Предметные
формулы и правильные программы передаются только Python-учителю/оценщику,
не Rust-ученику. Операции арифметики изначально доступны; их открытие с нуля
не заявляется. Добавлена общая операция точного целочисленного деления;
прежние продукции автономного синтезатора не изменены.

Из 64 примеров одной формулировки 48 используются для поиска, 16 — для проверки
первой найденной программы. Неуспех проверки не разрешает подбирать следующий
кандидат по тем же проверочным ответам. Библиотечные функции переиспользуются.
Языковая привязка пока в основном шаблонная; дополнительное лексическое
сопоставление обучается только на формулировках учителя.

Факты хранятся отдельно как вопрос/ответ с источником. Дословное воспроизведение
и лексическое извлечение отмечаются как teacher_recall/lexical_retrieval;
вычисление — induced_vm/induced_vm_lexical. Противоречивые записи не превращаются
в произвольный уверенный ответ. Источник — происхождение утверждения, а не
доказательство его истинности.

Знания сохраняются с организмом и замораживаются до экзамена. answer_school
читает состояние, не обучает его. Сохраняется общий выбор предложений U1,
однако большинство учебных вопросов имеют только одно допустимое предложение.
Поэтому нового доказательства преимущества нейронного управления здесь нет.
Это ограниченный интерфейс числовых знаний и памяти, не полноценное понимание
языка, причинная модель школьных знаний или самоизобретение всего мышления.

Файлы: src/education.rs, src/education_runtime.rs,
src/construction/induction.rs, src/bin/aeterna-unified.rs,
tests/education_runtime.rs, scripts/education_experiment.py,
scripts/education_verify.py. Контракт: SCHOOL_PROTOCOL.md.

## Выполненное обучение

- 3328 числовых примеров: 26 авторских тем, по две формулировки (RU/EN),
  по 64 примера. Все 52 группы прошли проверку 16/16.
- 3370 вопросов-ответов из TRAIN официального школьного набора Ai2 ARC:
  2251 ARC-Easy + 1119 ARC-Challenge. Это английские естественнонаучные Q/A.
- В памяти 6698 записей: числовые примеры также доступны контролю recall-only.
- Получены 22 вычислительные функции и 52 привязки формулировок. Это не
  52 независимые общие способности. В данном обучении не измерялось
  рекурсивное улучшение конструктора поиска.
- Учёт работы обучения: 3261130 единиц внутреннего счётчика, не FLOPs.

Темы включают арифметику, площади, объёмы, проценты, стоимость/сдачу,
среднее, единицы времени/длины/массы, скорость/расстояние/плотность,
целочисленную долю и простую последовательность. Выбор тем, формы вопросов
и порядок уроков подготовлены человеком. Это управляемое обучение,
не самостоятельно найденная учебная программа уровня ребёнка.

### Внешние школьные вопросы

Использован `allenai/ai2_arc`, ревизия
`210d026faf9955653af8916fad021475a3f00453`. Это НЕ интерактивный ARC-AGI-3.
TEST-файлы загружены только после обучения на TRAIN, заморозки и записи хеша
checkpoint. Экзаменационные ответы не направлялись в teach/facts.
Все вопросы TEST сохранены в журнале, ничего не отобрано по успешности.

| Поднабор | Все вопросы: правильно | Точные совпадения с обучением | Без точных совпадений: правильно |
|---|---:|---:|---:|
| ARC-Easy | 12/2376 | 7 | 8/2369 |
| ARC-Challenge | 1/1172 | 9 | 0/1163 |
| Итого | 13/3548 | 16 | 8/3532 |

Среди 3532 вопросов без точного совпадения с обучением программа выдала
22 непустых ответа; 3510 раз отказалась. Из этих 22 только 9 сопоставились
ровно с одним вариантом ответа оценщика, 8 оказались правильными.
Все восемь получены lexical_retrieval, не новым естественнонаучным рассуждением.
Удалены только точные нормализованные совпадения вопросов; близкие перефразы
между TRAIN и TEST не исключались. Поэтому даже эти восемь нельзя выдавать
за доказательство нового вывода из научных знаний.

ВАЖНО: использована диагностика СВОБОДНОГО ОТВЕТА. Ученик получает вопрос,
а оценщик отдельно сопоставляет его ответ с вариантами Ai2. Варианты ученику
не передаются. Это не стандартный формат multiple-choice и НЕ официальный
балл ARC. Некоторые вопросы без вариантов неполны; такой протокол нельзя
использовать для честного сравнения с человеческим результатом или таблицей
моделей. Он выявляет слабое извлечение ответа в этом интерфейсе. Языковой
контраст 16/208 отдельно показывает ограниченность даже числового применения.

## Запуск

Windows-пакет `aeterna-school-Windows-a0c7db1d` содержит exe, learned-school.json,
START-SCHOOL.cmd, README_RU.txt, SCHOOL_PROTOCOL.md, DATA_NOTICE.txt и SHA256SUMS.
Открыть START-SCHOOL.cmd, ввести вопрос; /exit завершает сеанс. Rust, Python,
LLM и сетевые запросы для этого готового пакета не требуются.

Исходники:
```
cargo test --locked --test education_runtime
cargo build --locked --release --bin aeterna-unified
python scripts/education_experiment.py --binary target/release/aeterna-unified --output school-results --external
python scripts/education_verify.py school-results
```
Эксперименту нужен Python 3.12 и pyarrow 19.0.1. Установки выполняет CI.
Повтор на том же открытом наборе является воспроизведением, не независимым
новым экзаменом. ARC-AGI-3 в этом продолжении не запускался, прежний 0/7
не изменился.

## Граница результата

Реализовано обучение ограниченным вычислениям по Q/A, сохранение, источник
фактов, ограниченный языковой перенос и проверяемый замороженный экзамен.
Интеллект уровня 12 лет не создан и не подтверждён. Не реализованы достаточное
общее чтение/объяснение, перенос научных причинных понятий и открытое решение
новых бытовых/визуальных задач. Возрастная норма не измерялась. Увеличение
объёма той же Q/A-памяти само по себе этот разрыв не устранило.

Clark et al. (2018), https://arxiv.org/abs/1803.05457 .

в преобразованной Q/A-памяти и экзаменационном журнале сохранена атрибуция.
Код сохраняет лицензию репозитория.
