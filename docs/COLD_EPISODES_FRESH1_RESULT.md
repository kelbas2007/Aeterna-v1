## What was compared (full cold lifetimes)

A and B each used a fully cold `ScientificRuntime` per world case. Both had the same agency-aware native U1 credit rule and the same factual Learner, initial motor/sensor dimensions, goal (progress >=1), resource budgets, HumanProtection permit and **all four offered motors for every real action**.

A: factual U1 only.
B: additionally enabled one-step predictive history state learning and U1-selectable causal pair probing.

Each world had 24 goal episodes and up to 18 actual protected action opportunities per episode. External world restart provided only the actual fresh numeric observation; U1 and Learner state remained persistent across episodes. No manually selected teaching motors, synthetic POST rows or leaked hidden actuator roles. The four transition families and 8 unique seeded opaque motor permutations per family were new to this source-disclosed experiment (not the old T-SR1/T-SR2/AGENCY-CREDIT2 worlds).

The source code implements these families and is inspectable: mode-choice hidden switch; ordered two preparations then use; time-window plus bridging step; unconditional direct-progress no-hidden-effect control. This is not third-party environment independence and not a general POMDP benchmark.

## Meaningful positive evidence (NOT full qualification)

The machine can physically collect its own informational PRE/action/POST experience without any tutor-selected primitive action, preserve it over external episode restarts, reconstruct limited action-history distinctions and actually select plans based on those distinctions in at least one new synthetic causal family. These are real engineered capabilities, unlike a label-only/planned-only test.

## Why this is NOT AGI or generalized self-improvement

The causal family code is source disclosed, with environment-provided goal and resets; latent-state inference is one predecessor deep and the active-probe candidate is an authored bounded heuristic. AETHERNA did not invent its own history grammar, higher-order latent variables, external worlds or safety criterion. Better global totals conceal important failed causal families and absence of early-to-late learning gain.

**Next architectural barrier:** learn predictive equivalence classes with variable-length executed action suffixes and distinguish cases where a sensor no-op changes later controllability; require prospective separate heldout consequences, independently contrasted histories and preservation of existing controls. Do not manually tune U1 weights or reuse any of these 32 known role maps as a "fresh" qualification test. A new protocol must precede a genuinely disjoint next scientific cohort.
