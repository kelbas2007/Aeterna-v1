## Authoring the smallest possible architectural correction

Do NOT add an independent agent or pre-scripted sequence; reuse same
actual Learner, native U1, checkpoint, and action protection.
Create an opt-in **empirical observable-state graph** from ONLY the
organism's own real and chronologically recorded PRE/action/POST rows.

- Each graph node is a factual full sensor observation vector,
  *not* a goal label, imagined state, word, motor role or latent
  evaluator stage. A directed edge `(PRE, motor, POST)` exists
  only when that exact transition was physically executed at
  least once and `POST != PRE`.
- Reject an edge if any real contradictory POST is found for the
  same full PRE and physical motor in the scanned bounded journal.
  Keep this "contradicted" status sticky within the scan.
- A bounded breadth-first search (max route depth
  `min(planning_depth,5)`, max 128 visited sensor states) discovers
  a path of at least TWO observable state transitions to the
  externally masked goal. No search returns a goal if the route's
  measured POST does not satisfy the masked goal.
- Source of proposed route is `observable-empirical-route`, NOT
  `factual-chain`: the evidence is observed but does NOT pass the
  older special three-future-POST certification. This is explicitly
  tentative. Do not relabel evidence support as scientific certainty.
- Entire route must be affordable from actual offered motor quotes;
  otherwise no candidate is proposed. One native U1 decision
  selects the plan, using the existing TemporalOptionLane. Each
  subsequent motor must receive a fresh HumanProtection permit,
  REAL POST and true cost; any expected/actual POST difference,
  reset or goal change cancels route. Only terminal observed goal
  may reward the initial U1 choice. No physical motor is executed
  by BFS or the proposer itself.
- Preserve invisible-history mode and all prior external
  checkpoint hashes. A separate cold-only opt-in flag is persisted
  with `serde(default,skip_serializing_if=Not::not)`, so legacy
  V1 TemporalOptionLane serializations remain intact.
- Charge scanning and BFS to a reserved fixed share (at most
  16k units) of existing finite planning-work budget. No new
  actuator authority, no RSP2/LC1 source change, no new dependency.
- Keep default behavior and original certified chains UNCHANGED
  unless this new opt-in is explicitly enabled BEFORE experience.
