# U3 — CROSS-MECHANISM RESIDUAL ALLOCATION THROUGH UNIFIED META-CONTROL

Status: **PRE-REGISTERED BEFORE U3 IMPLEMENTATION**
Date: 2026-10-07
Prerequisites: U1 PASS, U2 PASS on `unified-cognition`.

## Question

When the same decision-relevant residual could plausibly be explained by different acquired cognitive structures, can AETERNA allocate attention/experiments across those explanations using the same carrier-owned proposal/ecology system rather than a fixed module order?

U3 is the final architecture gate before INTEL-2.

## Competing explanation classes

Use three already-qualified mechanisms as proposal sources:

1. contextual/history refinement;
2. current-sensory perceptual/compositional refinement;
3. rival-transition / law revision.

The production meta layer must receive only opaque proposals with carrier-derived generic fields.

No source/module ID may alter proposal score.

## Shared fields

Every proposal must derive task-agnostic bounded values for:
- goal value;
- epistemic value;
- contradiction pressure;
- confidence/evidence quality;
- economy/cost.

Proposal IDs are opaque provenance only.

## Ecology registration

Each active explanatory structure registers into U2 ecology exactly once.

Candidate authority influences its U1 confidence/evidence field.

Stale/irrelevant explanation structures remain stored but lose authority through factual usefulness.

Useful structures can reactivate.

## Mixed residual witness

Construct a persistent world with three successive residual regimes and NO world/change flags.

### Regime H — hidden history is the useful explanation
Raw current observation is aliased; predecessor history predicts the correct outcome.
Raw-feature and law-revision candidates are plausible but nonpredictive.

Required:
- context proposal wins meta competition;
- factual follow-up raises context ecology authority;
- irrelevant perceptual/rival candidates lose authority.

### Regime P — current raw feature is useful
History becomes nonpredictive; a current raw feature predicts the relevant consequence.

Required:
- perceptual/compositional proposal becomes winner without host mode switch;
- former context structure remains stored but loses authority;
- raw-feature candidate gains utility from factual outcome.

### Regime L — transition law actually changes
Neither history nor raw feature explains the residual; rival-law experiment/revision is useful.

Required:
- rival/law proposal becomes winner;
- previous context/perceptual structures remain stored;
- law-revision structure gains authority.

## Transfer/revisit

After H -> P -> L, return to an H-like regime with no reset.

Required:
- old context structure reactivates and wins again without re-registration.

Target authority sequence:

```text
context -> perceptual/compositional -> rival/law -> context
```

The evaluator may score these roles, but production cognition receives only opaque proposals/fields.

## Controls

1. fixed authored module order baseline;
2. zero U1 meta weights;
3. zero U2 ecology weights;
4. lesion winning U1 meta synapse;
5. lesion winning U2 candidate utility synapse;
6. pi phase shift at each level;
7. exact restore;
8. proposal enumeration reversed;
9. opaque IDs re-keyed.

## Source guard

Unified production source must not contain:
- module priority arrays;
- ContextualRefinement / PerceptualRefinement / RivalDiscrimination names inside scorer;
- world/task IDs;
- correct explanation labels;
- regime H/P/L labels;
- authored per-class utility constants.

## PASS

U3 PASS requires:

- correct explanation-role winner on every scored regime transition;
- H->P->L->H authority switch without world/change signal;
- no candidate deletion required for switch;
- old H candidate reuses same physical address on return;
- fixed-priority baseline materially worse;
- zero-meta / zero-ecology controls fail;
- U1 and U2 physical lesions causally alter winner;
- exact restore recovers;
- order/ID invariance;
- U1/U2 weights change only through their own factual utility updates;
- G20-G23 and Human Protection regressions PASS;
- Release build PASS.

## Boundary

U3 PASS would establish bounded unified allocation among heterogeneous cognitive explanation classes.

Only after U1-U3 PASS may a frozen-core **INTEL-2** be opened on new target worlds.

No additional G24/G25-style mechanism ladder substitutes for INTEL-2.
