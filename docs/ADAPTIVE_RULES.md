# Условные правила, шум и непрерывное обучение

Разработка от 9 октября 2026 года. Отдельный опциональный режим полных
наблюдений, использующий [круговой словарь формул](EXPANDED_RULES.md).
Частичные наблюдения и [обратный вывод](INVERSE_INFERENCE.md) остаются
отдельным режимом точных моделей.

## Приобретение условий

Система получает только полные фактические PRE/POST после разрешённых
действий. Она сначала пытается подтвердить одну формулу для каждого выхода.
Если единой модели недостаточно, ищет разделение по одному наблюдаемому
каналу. Источник условия, граница, формулы обеих сторон и их смещения
определяются по данным. Метки контекста, номер режима среды, готовая граница
и значения коэффициентов от оценщика не поступают.

Язык условий фиксирован: один порог одного исходного канала, две ветви.
Сохраняются последняя точка слева и первая справа. Между ними модель
воздерживается от прогноза. Это интервал неопределённости границы, а не
точный закон, доказанный конечным числом примеров. За пределами интервала
действует индуктивное предположение о применимости соответствующей ветви.

Численный сдвиг хранится только в физических `PhaseSynapse::phase_offset`.
Источники и коэффициенты задаются выбранной структурой кандидата. Чтение
обеих связей двухканальной формулы обязательно. Поиск условия, его диапазон
и управление моделями являются программным алгоритмом и метаданными;
полное фазовое владение всеми когнитивными операциями не заявляется.

## Работа с шумом

Для каждого кандидата оценивается круговая медиана сдвига по нескольким
переходам. Подтверждение требует уникальной формулы, достаточного числа
различных PRE и заданной доли измерений, укладывающихся в допуск. Несколько
допустимых формул оставляют модель неподтверждённой. Близкие повторения PRE
не создают новую поддержку: порог различия равен удвоенному допуску остатка.

Основные настройки `PhaseAdaptiveConfig`:

| Настройка | По умолчанию |
|---|---|
| `min_support` | 6 различных подтверждений каждой ветви |
| `residual_tolerance` | 0.002 кругового отклонения |
| `min_inlier_fraction` | 0.9 |
| `goal_tolerance` | 0.01 для фактического измерения цели |
| `change_support` | 6 последовательных различающихся противоречащих PRE |
| `evidence_capacity` | 64 сохранённых перехода на действие, максимум 128 |
| `model_slots` | 4 физических слота на действие, максимум 8 |
| `fit_budget` | 1 000 000 проверок пар «кандидат — пример» за обновление |

Доля согласных измерений — эмпирический критерий, не калиброванная
вероятность истинности. В проверке ограниченного шума используется доля
1.0: все измерения должны соответствовать приобретённой формуле в пределах
допуска. Проверка отдельного выброса использует обычную настройку 0.9.

`PhaseAdaptiveForecast` имеет `Authority::Imagined` и радиус неопределённости.
При поиске цепочки действий радиус растёт с коэффициентами преобразований;
ветвь с неопределённым условием не используется. При выборе условия учитывается
также допуск ошибки самого измеренного контекста, включая первый шаг. Если
его круговой интервал пересекает ноль, система не выбирает ветвь по центру.
Прогноз плюс радиус должен
помещаться в допуск цели. Сам успех определяется последним фактическим
измерением. Радиус представляет заданный инженерный контракт ошибок,
не статистическую гарантию для произвольного распределения шума.

## Пересмотр и сохранение прежних знаний

Одиночный выброс не отзывает действующую модель. Последовательные реальные
противоречия на различных PRE приводят к пересмотру. При изменении закона
предыдущая модель с физическими параметрами и ссылками на основания
перемещается в архив, а новая модель приобретает другие слоты.

Если прежний закон возвращается, архивная модель активируется после
проверки на новых противоречащих текущей модели фактических переходах.
Воображаемый поиск или установка цели не активируют архив. Неподдерживаемый
контекст считается пробелом покрытия, без немедленного уничтожения старого
закона. Замораживание запрещает обучение и переключение архивных моделей.

Архив ограничен физическими слотами. Четыре слота позволяют хранить две
ветви действующей и две ветви предыдущей модели. При дальнейших изменениях
старейший архив может быть вытеснен; это учитывается в `evictions`.
Сохранение всех когда-либо приобретённых навыков не обещается.

## Бюджеты и сохранение

```rust
evo.enable_phase_native_online_learning(PhaseOnlineConfig { max_states: 1 });
evo.enable_phase_rule_learning_with_language(
    PhaseRuleConfig::default(), PhaseRuleLanguage::CircularAffine);
assert!(evo.enable_phase_adaptive_rules(PhaseAdaptiveConfig::default()));
let mut rt = ScientificRuntime::new(evo)?;
```

Режим включается до первого обучения правилам. Нужно заранее выделить
`channels × actions × (model_slots + 1)` свободных выходных ячеек вместе
с исходным словарём. Общий бюджет всех физических связей — 32768; превышение
проверяется до мутации. Восприятие новых состояний не создаёт receptors.
Наблюдения не увеличивают число ячеек, связей или слотов. Долгая жизнь
обновляет ограниченные примеры, модели и численные счётчики.

Бюджет fitting ограничивает работу на одном обновлении; неполный поиск
условий не публикует новый результат. Для планирования используются прежние
бюджеты глубины, ширины и узлов. При ограничениях модель может остаться
неподтверждённой даже для представимого закона.

Checkpoint v7 сохраняет условия, действующие и архивные физические модели,
ограниченные примеры, ожидающие подтверждения противоречия и источники.
Текущий REAL кадр и внешнее право действия не сохраняются. Читаются v1–v5;
новые режимы нельзя объявить файлом старой версии. Проверяются адреса,
размеры, слоты, шаблоны кандидатов и источники; это структурная валидация,
не удостоверение происхождения файла.

После загрузки нужен свежий фактический кадр. Живые freeze и emergency stop
сохраняются. Предел файла 16 МиБ не является измерением или гарантией
пикового потребления RAM во время сериализации.

## Пример в двух процессах

Путь для `learn` должен ещё не существовать:

```bash
cargo run --locked --release --example adaptive_learning -- learn /tmp/aeterna-adaptive.json
cargo run --locked --release --example adaptive_learning -- run /tmp/aeterna-adaptive.json
```

Во внешней среде наблюдаемое условие меняет численный закон действия.
Датчики вносят ошибку ±0.00035. Среда меняет оба закона на новые, затем
возвращает исходные. Все 768 действий приобретения идут без перезапуска
когнитивной системы или замены её текущего состояния.

Фактический результат двух отдельных процессов:

```text
mode=learn continuous_actions=768 conditional_actions=2 archived_models=2 reactivations=2 goal_actions=1 factual_goal=true frozen_unchanged=true
mode=run continuous_actions=0 conditional_actions=2 archived_models=2 reactivations=2 goal_actions=1 factual_goal=true frozen_unchanged=true
```

## Проверки и пределы результата

`tests/adaptive_rules.rs` содержит семь направленных проверок:

| Проверка | Результат |
|---|---|
| 16 шумных миров, перестановки каналов и действий, самостоятельно найденные условия | 256/256 новых целей; модель того же языка без условий — 0/256. Обоим режимам дано по 256 действий обучения и одному действию на цель |
| Шумные сдвиги, одинаковые 32 фактических перехода | Режим с накоплением поддержки подтвердил модель, точный прежний режим остался неподтверждённым |
| Закон A → B → A, архив и сохранение фазовых параметров | 32/32 целей после изменения, 32/32 после возврата; прежние параметры сохранены и модель повторно активирована |
| 2048 действий обучения | Топология не растёт, история ограничена; checkpoint 81 881 байт в проверенном примере |
| Отключение, π и точное восстановление связей | Прогноз зависит от приобретённых параметров, без запасного численного закона |
| Неопределённый контекст пересекает круговую границу 1 → 0 | План не выбирает ветвь условия по одному центральному значению |
| Неоднозначность, повторения, нелинейный закон, бюджеты, повреждение файла, остановка и плохой POST | Неподдержанные модели не подтверждаются; действия и фактическое обучение сохраняют прежнюю внешнюю границу |

Каждая тестовая функция проверяет несколько связанных случаев.
Сравнение шумных миров использует одинаковые
бюджеты и начальные условия, но самостоятельные траектории действий каждого
обучаемого режима. Оценка новых целей заморожена и проходит после дискового
восстановления. Генераторы и бюджеты открыты и синтетические.

Пока не поддерживаются сложные логические условия, несколько порогов,
ненаблюдаемый контекст, произвольные программы, автоматическое определение
закона шума и общий поток текстовых знаний. Режимы обратного вывода и шумного
условного обучения проверены отдельно. Эти результаты не заменяют прежние
INTEL/TE qualification и не доказывают общий интеллект.

## Общая проверка разработки

`bash scripts/check.sh` прошёл: 125 успешных test invocations, 0 failed,
8 ignored и 79 filtered в 29 запусках тестовых бинарников. Общие fixtures
повторяются; это не 125 независимых экспериментов. После уточнения допуска
ошибки контекста отдельно повторно прошли все семь проверок adaptive rules.
Сборка всех bins/examples, `cargo check --locked --all-targets` и Clippy
correctness для библиотеки прошли; прежние предупреждения сохраняются.

Новые learn/run-примеры прошли в отдельных процессах. Текущие бинарники также
успешно прочитали настоящие сохранённые файлы v4 всех четырёх прежних режимов
и v3 трёх прежних режимов. Development CI включает оба новых набора и примера;
удалённый workflow в рамках этого изменения не запускался.
