## Architecture hypothesis

The missing capability is not another representation class.

It is a **carrier-owned developmental agenda**:

> persistent cognitive projects that own their evidence debt, request experiments over multiple actions, receive hypothesis-local causal credit, terminate when resolved, and permit alternative hypotheses to be generated after rejection.

U1-U3 remain useful substrate but their frozen one-step assembly is insufficient.

## A. Utility semantics: confidence is not benefit

The frozen U1 action score treated physical support confidence as a positive additive utility field.

That can create self-lock:

```text
first sampled action
 -> more support/confidence
 -> higher meta score
 -> sampled again
 -> siblings remain unknown
```

In the developmental architecture:

- goal improvement is benefit;
- expected information gain is benefit;
- contradiction reduction is benefit;
- cost/economy affects net value;
- confidence/reliability may modulate a predicted benefit;
- confidence alone MUST NOT make an otherwise useless action preferable.

A pure epistemic unknown action must not lose merely because a known action has greater support confidence.

## B. Persistent cognitive project

A project is a physical/provenance-bound unresolved question, not a module label.

Minimum state:

- stable project/candidate ID derived from carrier provenance;
- physical project cell / utility pathway;
- current applicability;
- local evidence strength;
- evidence debt / missing coverage;
- local progress since previous observation;
- stagnation count;
- resolved-positive / resolved-negative / dormant status;
- action(s) that can reduce its evidence debt;
- generic estimated goal/information benefit and cost.

Context, perceptual, compositional, rival-law and model-coverage questions may all instantiate projects through the same lifecycle.

## C. Evidence debt / experiment commitment

Evidence-gated structures often require multiple deliberately distributed samples.

A project may therefore remain competitively active while:

- it is unresolved;
- its evidence debt is decreasing;
- its predicted information gain remains positive.

This is NOT a host lock that forces a module to run.

The project competes through carrier-owned utility each step, but receives explicit expected information value for satisfying its own remaining evidence obligations.

Examples of generic obligations:
- untested action at an applicable state;
- unobserved side/condition for a candidate;
- insufficient repeated support;
- unresolved competing successor predictions.

No world/task ID enters the obligation.

## D. Hypothesis-local causal credit

Remove global credit of the form:

`any learned-state change => selected hypothesis useful`.

A project receives positive learning credit only from:
- actual goal/task outcome attributable to its selected action;
- increase in that SAME project's evidence strength;
- decrease in that SAME project's evidence debt;
- successful resolution of that SAME project's contradiction/prediction.

Accumulating evidence that makes the project less plausible must not raise its long-term authority merely because some global counter changed.

## E. Alternative-hypothesis succession

A rejected candidate must not permanently occupy the only candidate slot for a residual.

Requirements:

- retired candidates keep provenance;
- later factual residuals on the same base may generate structurally distinct alternatives;
- exact previously tried candidate structures are not regenerated indefinitely;
- alternative generation is bounded by structural/resource ceilings;
- no evaluator feature/operator label is supplied.

This applies generically to context/perceptual/compositional candidate families where structurally meaningful alternatives exist.

## F. Finite architecture gate

Do NOT create another long G-series.

Before a new system verdict, one Developmental Agenda Gate must demonstrate ALL:

### F1 — anti-lock action coverage
On a new abstract state with six opaque actions:

### F2 — local credit
Two persistent projects are present.
- unrelated/global learning changes while project A makes no local progress;
- A authority must not increase from those changes;
- project B makes its own evidence progress -> B authority increases;
- negative evidence/rejection -> project authority decreases/dorms;
- causal synapse lesion/pi/restore.

### F3 — alternative hypothesis succession
On a raw residual:
- first candidate is plausible but wrong and is evidence-rejected;
- same base later generates a distinct alternative candidate;
- second candidate can promote;
- first candidate remains stored as rejected provenance;
- no host-selected operator/feature answer.

### F4 — multi-step evidence project
A history/raw/composition project requiring balanced evidence over multiple episodes:
- project evidence debt decreases;
- action allocation covers required conditions rather than repeating one motor;
- project resolves/promotes;
- after resolution, project relinquishes excess authority;
- unrelated old projects remain stored but do not monopolize.
