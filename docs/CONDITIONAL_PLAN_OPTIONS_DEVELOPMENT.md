# CONDITIONAL-OPTIONS1 — acquired causal route as a bounded temporal action option

2026-10-19, developer-authored developmental protocol, committed BEFORE implementation. This is NOT another one-use cold-transfer science run or an independent AGI claim.

## Disclosed diagnostic motivating the change

An existing Learning/U1 prospective option inferred a real two-action hidden-state suffix after source-disclosed, actually executed PRE/action/POST identification. In Linux test `ADAPTIVE_SUFFIX_FIRST`, U1 chose a correct invisible first action. But the added fully unforced 12-step continuation regressed: candidate actually chose the first TWO prerequisites (sources `predictive-suffix`), then abandoned the needed third motor due native U1 tie/random choice. It failed the goal. This failure remains public in the original job and is NOT accepted as a pass. This is a temporal execution/commitment problem, not absence of the causal edge.

## Research intervention

Add an **opt-in, bounded native-U1-chosen causal option** to the SAME existing `ScientificRuntime`: the learned planner returns an actual prospective-certification-backed full action/visible-post route. If and only if **U1 itself selects** the option's first action, the organism may hold its remaining route as a coherent *temporally extended choice*.

Each subsequent member of the saved option:
1. may execute only with a fresh HumanProtection permit, quoted available motor and remaining real budget;
2. must begin from a previously witnessed physical POST matching the stored expected state; after every real POST, an unexpected observation cancels all future steps, and no fabricated learner evidence is written;
3. must be canceled on a changed goal, external world restart/domain switch or missing motor, and cannot persist beyond the original short route budget;
4. is a **continuation of the initial native U1-selected cognitive option**, NOT a second external teacher choosing motor IDs. This is higher-level agency: the native selector chooses the plan, then its learned substeps execute as its option under protection. Mark continuation steps separately, never credit U1 as having made a NEW primitive decision at each automatic continuation;
5. earns delayed option-level U1 credit only after an actually observed successful terminal goal POST, and preserves factual learning regardless of outcome; no rewards for predictions alone.
6. stores the bounded option, progress and accumulated executed costs in the existing hashed joint checkpoint. Falsified, out-of-range or stale options must fail restore validation.
