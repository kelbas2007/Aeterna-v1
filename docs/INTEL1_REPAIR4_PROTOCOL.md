## Preserved verdicts

## Earliest R3 bottleneck

In one persistent lifetime, earlier worlds can create contextual candidates on a physical base cell that is later reused in a qualitatively different world. G21's current rule:

`no candidate on this base -> candidate may be born`

and its first-candidate readout create cross-world interference.

## Allowed repair

Repair-4 may only generalize G21 contextual hypothesis management.

A base state may own multiple bounded competing context hypotheses.

A candidate identity is task-agnostic and determined only by factual structure:

- base physical cell;
- anchor opaque action;
- unordered pair of predecessor physical cells;
- unordered pair of alternative successor physical cells.

A new collision may recruit a candidate if no non-retired/promoted candidate with the same structural identity already exists and the global candidate cap permits it.

No world ID, task counter, context label, reset-on-world-change, evaluator state ID or correct action may enter cognition.

## Readout applicability

For the current factual base and short-term predecessor:

1. ignore every context hypothesis whose predecessor pair does not contain the current predecessor;
2. unpromoted applicable hypotheses may request their own anchor experiment while learning is enabled;
3. promoted hypotheses are usable only through their physically coherent base and predecessor links;
4. if exactly one promoted hypothesis yields a physical refined state, use it;
5. if multiple promoted hypotheses simultaneously yield different refined states, fail closed for context readout rather than choose by host answer;
6. an unrelated old hypothesis MUST NOT block ordinary rival/goal/epistemic reasoning when it is not applicable to the current predecessor.

## Learning

Every factual collision is compared against bounded discovery history as before.

Candidate creation must suppress exact duplicate structural hypotheses, not all candidates sharing one base.

Every existing candidate receives evidence only when the factual predecessor belongs to that candidate's predecessor pair.

Evidence gate, sample limits, alpha, promotion threshold, physical synapse learning, checkpoint semantics and candidate cap remain unchanged.
