## What changed in the organism

The new opt-in native mechanism in `src/phase_contextual.rs` can detect that a single acquired perceptual state conflates different histories. It selects a candidate from an actual factual collision, recruits two prospective contextual state cells, and learns their consequences using the ordinary native transition circuitry.

The first collision only selects the hypothesis. The evidence used to promote it comes from later actual observations. Those counts are read from the support metadata of the acquired physical contextual transition circuits; the discovery observations are excluded.

Each contextual state requires two acquired input pathways: the current base observation and the actually observed predecessor. Correct action readout comes from phase-sensitive contextual activation and the existing native goal recurrence, not an evaluator-provided context-to-action mapping.

`ScientificRuntime` invokes this native path without exposing a context-label, split-command or answer-table API. Its mandatory Human Protection screening and single-use permit consumption remain before every execution callback.

## Physical dependence and persistence

For each of the two contexts in each variant, the completed tests checked the acquired predecessor-input synapse:

1. Its weight set to zero makes contextual readout unavailable.
2. Shifting only its phase by pi also makes that readout unavailable.
3. Restoring the exact saved synapse restores the correct action without training and restores the learned fingerprint.
4. Damaging the other context's input link leaves the target decision correct.

There are four targeted context checks, not 128 lesion trials. These interventions establish dependence on the specified simulated carrier links in this fixture. They do not establish that all learning, selection and inference equations are emergent oscillator computations.

Both contextual consequences remain usable instead of the parent model continually erasing whichever consequence was not seen most recently. Merely proposing an action or executing frozen scoring does not change the learned fingerprint; transient factual predecessor memory may advance.

A native checkpoint preserves acquired contextual evidence, addresses and transition knowledge, but clears the transient predecessor. Restarting at a junction with only its current image abstains rather than inventing the missing history. In the protected lifetime, restart at a factual cue followed by an actual cue-to-junction action restores usable context. This is in-memory cognitive persistence, not a power-loss or durable-disk recovery result.

## Statistical diagnostic and assumptions

The same frozen evidence gate was evaluated at every prefix of 512 preregistered stationary binary null streams up to 128 observations: **0 false promotions / 512**. The separate unit test verifies that the batch integrated binary likelihood equals sequential KT prediction updates.

An independent Python calculation using `math.lgamma`, rather than the Rust implementation's explicit log products, also returned 0/512. The reusable script is `scripts/g21_statistical_crosscheck.py`. That script and the explanatory research note were committed after the tested Rust source; they are not claimed to have run as part of this CI source snapshot.

The proposed optional-stopping argument is documented in `docs/G21_RESEARCH_NOTE.md`: the context-conditioned mixture likelihood divided by the pooled null maximum likelihood is dominated by a likelihood-ratio martingale under a fixed stationary conditional Bernoulli null. Spending alpha 0.01 over at most 16 future-only candidates then yields a union bound under those assumptions.

This is established statistical methodology applied here, not a newly invented theorem. The finite 0/512 result is an arithmetic/regression diagnostic, not proof of general noise robustness. The argument does not cover arbitrary drift, dependent sensor errors, confounding outside the stated null, or unlimited adaptive candidate replacement. Statistical alpha is unrelated to Human Protection risk thresholds.

## Research significance and limits

The supported project-level advance is **operational representation repair during the same protected lifetime**: a recurring prediction conflict can lead to a new history-dependent state distinction, validated by separate later facts and then used to choose correctly where the old memoryless representation cannot.

State splitting, predictive/causal state representations, selective history use and anytime-valid evidence have prior literature. No worldwide uniqueness or performance superiority to U-Tree, recurrent networks, predictive-state models, or always-contextual methods is established. The memoryless comparator is deliberately weaker and isolates the value of the new distinction; it is not a state-of-the-art learning baseline.

The inherited raw perceptual vocabulary remains fixed for this experiment. Context search is restricted to one immediately preceding acquired observation and two predecessor categories. The runtime still rejects an entirely unrecognized raw abstract state. Longer histories, new sensory primitives, stochastic action selection, contextual rule drift after promotion and broad independent task families remain unqualified. Candidate selection, evidence equations, diagnostic action repetition and orchestration are programmer-defined generic rules.

The next scientifically useful evaluation is not another claim of general intelligence: it is independently sampled, harder partial-observability tasks with longer/distracting histories, stochastic consequences, matched sample/compute budgets and strong history-aware baselines.
