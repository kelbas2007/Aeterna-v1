# AETERNA PR9: prospectively validated factual chains — experiment boundary

Date: 2026-10-19. **EXPOSED DEVELOPMENT ONLY. NOT QUALIFIED AUTONOMOUS TRANSFER.**

## Next barrier

Previous PR9 can identify a two-condition numeric effect from observed
PRE/action/POST transitions, subject to independent contrasts and later
chronological holdout validation. It does **not** thereby plan the actions
needed to establish both prerequisites from a new start state.

## Research change

The existing Learner may now search a bounded chain of candidate actions.
For each imagined edge it first performs a cheap *rejection-only* inference;
any usable edge MUST independently pass the existing prospective
calibration against three newer *executed real* transitions of that motor.
Unknown or contradictory effects are not inserted into the search.
The search uses the existing explicit computation work meter, state/expansion
caps and planning-depth limit. If and only if a fully certified path reaches
the masked goal in 2+ steps, its first action joins U1 as a
`factual-chain` proposal. U1 continues to arbitrate; HumanProtection owns
the actual action; only the actual external POST is recorded. The terminal
value is discounted for chain depth. No imaginary journal entries.

This is opt-in research, and is attempted only in numeric construction
configurations with `planning_work >= 32000`. Previous 4k and 20k
development baselines remain unchanged. All paths are re-evaluated from
the current factual journal, so contradictory post-action consequences
withdraw the old plan instead of preserving an unverified certainty.

## What the new local test measures

The unit fixture spans independently varied prerequisite sensor settings
and three opaque action IDs. One motor changes prerequisite A, another
changes B, and progress responds only when both are true. A goal-directed
three-action factual chain must be inferred from observations, and must
abstain if a prerequisite motor is unavailable, evidence computation is
underfunded, or later real consequences contradict the acquired effect.

**Important limitation:** fixture Record rows are synthetic unit data, not
actual protected external-action acquisition. The new test verifies inference
and planning mechanics; it is not evidence that U1 consistently SELECTS
that proposal in an unseen world, that it autonomously discovers all
required observations, or that broad transfer occurs.

## Promotion criteria (NOT satisfied by this test)

1. Full exact-head Linux and Windows CI, source-binding audit and all
   old paired 4k controls pass with no regressions.
2. A separate protected-execution trial demonstrates both acquisition
   from actual POST events and selected multistep physical action;
   same journal for matched baseline U1, different goal/initial state.
3. A future independently specified, disjoint task family demonstrates
   no-regression plus a meaningful action-efficiency improvement, without
   adjusting policies on the resulting hidden outcomes.
4. When new evidence conflicts, certification must be revoked; journal
   and HumanProtection permits remain authoritative across checkpoint.

No general-intelligence, independent goal creation, transfer or autonomous
causal discovery claim is made from this experiment.
