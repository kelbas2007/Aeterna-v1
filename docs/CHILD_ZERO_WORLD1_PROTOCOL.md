# CHILD-ZERO-WORLD-1 — inherited cognitive readiness in external worlds

Date 2026-10-10, OPEN DEVELOPMENT, not an independent source-sealed AGI gate.
This experiment follows the explicit user request that AETERNA should
not begin as a blank reinforcement-optimization program but should have
an organism-like set of initial *capacities* analogous to a newborn
human's sensory, attention, memory and bodily learning predispositions.

A newborn has automatic reflexes, sensory preferences and mechanisms
of learning, but does not have a complete mature object, language,
mathematics, physical-tool, moral or spatial ontology installed
as factual concepts. Source register and evidence caveats:
[CHILD_ZERO_INNATE_SCAFFOLD.md](CHILD_ZERO_INNATE_SCAFFOLD.md).

## Hypothesis and frozen experimental contrast
Does an INITIAL physically present learning predisposition together
with bounded running episodic experience memory materially improve
a generic action-conditional learned controller's real external
whole-task competence, compared to EXACTLY the same learned controller
WITHOUT these inherited sensitivities?

Source is the user's existing phase-native EvoPhase and independent
Farama MiniGrid 3.1.0 physics. The opt-in inherited circuits exist
before an experience is provided: eight first-class phase-link
prior categories (continuity, orienting, self-agency, habituation,
rough magnitude, regulation, social readiness, speech readiness).
Only five are currently meaningfully functional with generic
non-social binary observations; the language/social readiness
features CANNOT be exercised with categorical MiniGrid input.
No symbol "key", "door" or "goal" is preloaded at birth.

The second architectural option \`developmental_memory\` adds
a slowly carried experience trace to the action learner's
current observed features, so identical present images can lead
to different internal states after different factual histories.
This is a simplistic leaky trace, NOT a demonstrated concept
of self, body or persistent objects.

**Matched run**, same source/real world seeds/episodes/budget:
- Control A: generic single learned action policy ONLY, with
  no innate scaffold and no explicit history trace.
- Experimental B: same exact generic policy + eight physically
  gated initial predispositions + bounded within-episode memory.
- Four unmodified independent Farama software worlds: Empty-5x5,
  DoorKey-5x5, MultiRoom-N2-S4 and Unlock.
- Train seeds **72000..72011** per family in ONE continuous
  lifetime, 48 episodes. Native checkpoint, freeze learned
  weights, then heldout **73000..73003** per family, 16 tasks.
- Maximum 256 actually protected native motor actions per
  episode; U1 and Human Protection remain unchanged.
- Both arms receive only the public 7x7x3 partial category-coded
  image converted to binary sensory channels and actual bounded
  simulator reward. No simulator map, motor meaning, language,
  body/health state, object tutoring, route script or planned
  goal information enters either organism.
- A matched random baseline receives same heldout seeds/budget.

## Required outcome, not decorative "PASS"

Scientific score is actual positive simulator terminal reward,
NOT a readout of newborn-biased preferences, acquired association
count or guessed task success. Predeclared robust OPEN development
target: experimental B must have >=6/16 full heldout task wins
AND strictly exceed both A and random; include at least one
completed heldout DoorKey or MultiRoom, under valid source/runtime
checks. Otherwise report DEVELOPMENT_FAIL.

A separate native test requires eight nonzero physical prior
synapses before any external learning, zero initial object/word
memories, factual action contingency learning, same-source
lesion/restore of the orienting prior and frozen-model persistence.

This is *not* "all innate human concepts", and cannot become
one by enumerating words. Social/voice/physiological grounding
requires real sensory modalities and authentic developmental
interaction, not guessed flags. If the B result is negative,
do not post-hoc add "door" or "key" priors or pretend the model
became a child. The appropriate architectural diagnosis is
that numeric initial biases and a leaky feature trace are still
too far from predictive developmental cognition.
