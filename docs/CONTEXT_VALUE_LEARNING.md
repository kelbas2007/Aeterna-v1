# Контекстная ценность действий

Opt-in режим существующего общего контроллера. Он обучается по собственным
фактическим PRE/action/POST и внешней награде за завершение задачи. Обучение
ценности, адресация состояний и планирование по измеренным переходам написаны
на Rust; это не самостоятельное изобретение вычислительных примитивов.

[Результат](CONTEXT_VALUE1_RESULT.md) · [протокол](CONTEXT_VALUE1_PROTOCOL.md).

## Включение

В JSONL-адаптере после `init` и перед первым `reset` последовательно отправьте:

```json
{"cmd":"general_policy"}
{"cmd":"developmental_memory"}
{"cmd":"relational_workspace"}
{"cmd":"context_value_learning"}
```

Каждый ответ должен содержать `accepted: true`. Workspace адаптера рассчитан
на публичную категориальную сетку 7×7×3, кодированную четырьмя битами на поле:
588 сенсоров и семь непрозрачных моторов. `reset` получает только реальное
наблюдение и флаг обучения. `advance` выбирает действие через U1 и Human
Protection; `post` возвращает фактические сенсоры и награду в диапазоне [0,1].
Названия объектов, координаты карты, правильный выход и смысл моторов
контроллеру не передаются. Поддерживаются награды за завершение; промежуточные
положительные награды другого смысла требуют отдельного контракта.

## Что хранится

- До 2048 состояний с ценностями действий и частотами фактических исходов.
- До четырёх классов измеренных исходов для каждого состояния/действия.
- До 256 последних переходов текущего эпизода и 512 попыток для выхода из циклов.
- Ограниченная память фактически наблюдавшихся появлений объектов; число
  одинаковых появлений сохраняется, вместо потери информации при сведении к SET.

Least-recently-used вытеснение защищает активное PRE во время записи POST,
но может забывать старые состояния. Это ограниченный кэш навыка, а не
неограниченная энциклопедия. Прогнозные MODEL backups не увеличивают число
фактических наград или выполненных действий.

Чтение контекста и выполнение мотора требуют физических фазовых связей.
Табличные значения и вычисления остаются программными. Физическое отключение
связи доказывает необходимость этого пути доступа, а не полное владение
всеми когнитивными вычислениями EvoPhase.

## Замороженное использование и сохранение

`learning: false` запрещает изменение обученных значений, моделей и числа
сохранённых состояний. История текущих попыток остаётся доступной для выхода
из циклов и исследования неизвестного наблюдения. При `restart` native
checkpoint сохраняет приобретённые значения и очищает прошлую подсказку.

Этот checkpoint — копия native-состояния для нового объекта EvoPhase внутри
процесса. Текущий дисковый формат Online v9 не включает новый value head;
сохранение этого режима между запусками ОС ещё не реализовано. Дисковые
checkpoints остальных документированных режимов сохраняют прежние возможности.

Обычный `scripts/check.sh` проверяет причинные контроли и ограничения памяти.
Внешний эксперимент запускается вручную; его опубликованные seeds уже
использованы, повторный запуск не создаёт нового независимого свидетельства.
