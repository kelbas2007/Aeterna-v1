# ADAPTIVE-HISTORY-SUFFIX1 — prospective history-length selection

Date: 2026-10-19. Pre-implementation, EXPOSED developmental protocol. This is not the consumed COLD-EPISODES-FRESH1 cohort, and not an independent blind science qualification.

## Why

The source-frozen COLD-EPISODES-FRESH1 failed scientific transfer: AETERNA improved total virtual goal successes 407→432 /768 and actions 8824→8094, but regressions in the ordered-preparation and timed-prerequisite cohorts, no >10% action saving, and no early-to-late progress. Native U1 selected 155 history plans in the simplest hidden mode family but ZERO in both longer-prerequisite families. This is evidence of representation limits (or arbitration), not proof which alone caused failure.

The present `calibrated_history_effect` only conditions a motor's consequence on the immediately preceding executed motor. It cannot distinguish worlds that have identical visible PRE, same current action, SAME immediately preceding motor and different outcomes because of earlier actions.

## Minimal learner change

Add an opt-in **bounded variable-length action history context** (depth ONE or TWO selected from actual evidence) inside the existing `Learner`, not a separate planner/agent. No numeric motor semantics, author-defined 'charge' or 'key' labels, reference answers, synthetic POST or new actuator permission.

- A history suffix is valid only if EVERY adjacent executed PRE/action/POST pair has exact sequential event IDs, connected actual sensor readings, and no explicit external restart crossing.
- Test one-step calibrated effects first (unchanged). Only when a one-step state cannot explain a prediction may the learner consider suffix length TWO. A candidate length-two suffix must have **four older real positive-context transitions**, at least **four older negative-context transitions** sharing the same shorter suffix, and **three PRE-matched, different-POST controlled contrasts** before claiming a distinction.
- The three most recent real target-context actions MUST be chronologically withheld for prospective prediction using older evidence, then re-fitting on all allowed real data must agree with that prediction. No information beyond `frozen_at` may enter either training or validation.
- Search via a bounded BFS over (visible state, valid action suffix) and independently calibrated history-conditioned edges, with a maximum shared planning budget, visit/frontier caps and no synthetic journal rows. A repeated observed no-op can be an intermediate preparation only, never a terminal success.
- U1 receives exactly one optional ordinary proposal with a first motor; old U1 still chooses and HumanProtection approves and physically executes each action. Explicit research opt-in for longer suffixes is enabled only with existing short-history mode and planning_depth>=3; legacy 4k/20k and short-history experiments remain unchanged.
- Preserve learner flag in the existing checkpoint; reject invalid combination on restore.

## Precommitted EXPOSED engineering controls

1. Same protected ScientificRuntime, one real sensory progress channel and five opaque motors. A source-disclosed evaluator-only hidden rule needs **two distinct preparatory actions in an ordered pair** before an actual use motor changes progress. A control history has the SAME most recent preparatory motor and SAME visible PRE but a different earlier motor, which makes the final motor fail. All training facts come from executed, physically screened actions with a disclosed training schedule ONLY in the engineering fixture.
2. Short-history-only ablation must refrain from promoting the two-action-dependent goal route; variable-suffix opt-in must produce a bounded, grounded causal route whose first action is preparatory and whose endpoint is genuinely consistent with the learned real POST data. A complete human-independent world-learning claim is NOT made.
3. A null environment in which target outcomes do not depend on earlier history must yield NO spurious long-suffix plan. Unavailable preparatory motors, inadequate metering and HumanProtection veto MUST NOT result in an external protected action or an accepted plan.
4. Three new real contradictory POSTs in the context must retire the learned long-suffix prediction; episode restarts must sever causal history and restored checkpoints preserve exact results.
5. Test actual U1 selection separately from plan *availability*; a proposed path is not a completed action.

## Limitations and publication

Depth at most two actions initially; this is developer-authored syntax plus acquired concrete predictive distinctions, NOT autonomous invention of mental primitives, confidence against arbitrary confounding, probabilistic CSSR or AGI. These source-disclosed fixtures are intentionally NOT the COLD-FRESH1 cohort, but neither are they a new independent scientific result. Future independent source-frozen trial requires a NEW disjoint protocol committed before its world generator. Do not call green engineering tests self-improvement.

No change to RSP2 admission, HumanProtection or main. PR9 remains DRAFT.
