# G10 — AUTONOMOUS COMPOSITE CONCEPT CONSTRUCTION

Status: **PRE-REGISTERED BEFORE G10 IMPLEMENTATION**

Date: 2026-10-06

## Why G10 exists

G0-G9 now cover bounded structural learning, raw relational perception, active inquiry, acquired/revised programs, hierarchy, learned exploration, open-world nuisance robustness, imagined planning and recurrent belief state.

A central remaining weakness is representation formation: useful relational algebra is inherited, and many decisions still consume individual acquired structures directly.

G10 asks whether EvoPhase can create a **new reusable composite concept** from already acquired lower-level carrier units when no individual child is predictive enough.

## World

A raw 12x12 raster contains two spatially separated local two-pixel motifs.

Generic retinotopic phase algebra produces local relation vectors. The carrier clusters repeated local relations into acquired atom units.

Four evaluator-only relation families A,B,C,D are used only to construct the development world.

The task classes are XOR-like:

```text
class 0: {A,B} or {C,D}
class 1: {A,C} or {B,D}
```

Every individual atom therefore appears equally in both classes. No single acquired atom is sufficient.

The correct opaque motor is permuted between runs.

Cognition never receives:
- A/B/C/D names;
- class labels;
- motif coordinates;
- the target conjunction;
- the correct motor.

It receives raw raster, opaque motor ID and factual Need.

## Inherited substrate

Allowed:
- fixed local retinotopic radius;
- generic FHRR/HDC pair relation;
- clustering of repeated relation vectors into acquired atom IDs;
- generic enumeration of co-active atom-ID pairs;
- factual outcome statistics;
- structural promotion of a composite when its joint evidence is strong while child evidence remains weak.

Not allowed:
- host rule naming the useful atom pair;
- evaluator class label in production state;
- a hand-written XOR detector;
- a task-specific conjunction table.

## Composite concept

A concept contains:
- a stable carrier ID;
- references to acquired child atom IDs;
- action-conditioned factual evidence;
- support / utility / revision state.

The concept must be absent before factual tuition.

Promotion is allowed only when:
1. the child pair has sufficient repeated factual support;
2. at least one action has strong signed factual evidence for the pair;
3. each individual child remains below the frozen predictiveness ceiling for that action.

## Matched arms

GENUINE:
- atom learning ON;
- composite construction ON;
- composite readout OFF during tuition.

NO_CONSTRUCTION:
- identical raw experience;
- identical atom learning/statistics;
- composite construction OFF.

NO_READOUT:
- clone of GENUINE after tuition;
- composite readout OFF.

All arms receive the same fixed generic action exploration.

## Held-out

Learning frozen.

Held-out scenes use:
- absolute motif bindings absent from tuition;
- all four pair combinations;
- opaque motor permutations.

## Mechanism acceptance

PASS requires:
1. the same lower-level atom inventory is acquired in GENUINE and NO_CONSTRUCTION;
2. no composite exists before tuition;
3. GENUINE acquires composite concepts; NO_CONSTRUCTION acquires zero;
4. each promoted concept references acquired child atom IDs rather than raw evaluator labels;
5. measured individual-child action evidence remains below the frozen predictiveness ceiling;
6. composite evidence exceeds the frozen promotion threshold;
7. GENUINE solves all held-out pair combinations across both motor permutations;
8. NO_CONSTRUCTION and NO_READOUT lose a material part of the advantage;
9. successful action IDs follow opaque permutation;
10. G0-G9 regressions and ownership audits PASS;
11. optimized release build PASS.

## Fresh qualification after mechanism PASS

Use a new one-use authority pack with:
- >=80 worlds / >=10 sub-seeds;
- relation atom types sampled from a larger relative-offset pool;
- randomized pair-to-class assignments satisfying the no-single-child-predictiveness constraint;
- randomized opaque motors;
- held-out spatial bindings;
- Wilson 95% CI;
- matched ATOMS_ONLY / NO_CONSTRUCTION controls.

## Interpretation

A PASS would establish bounded self-construction of a reusable composite predicate from acquired carrier children.

It would not establish unrestricted concept invention, arbitrary arity, natural-language semantics or AGI.
