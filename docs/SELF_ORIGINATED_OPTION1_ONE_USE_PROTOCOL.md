## Hypothesis
An individual cold AETERNA can use *its OWN physically executed*
goal successes to propose and select a learned three-motor action sequence
in new, disjoint source-disclosed finite-state causal environments, improving
new goal attainment and real action economy without any tutor-designed motor
schedule. The motor alphabet is opaque. A complete matched behavior baseline
differs ONLY in the new autobiographical-option opt-in flag.

## One-use evaluation set and randomization
- EXACTLY four disjoint evaluator-only causal mechanics, NOT the previously
  exposed single fixed ordered A→B→C development environment:
  (F0) two INDEPENDENT persistent hidden affordance flags whose order
  does not matter, with explicit clearing action;
  (F1) a repeated SAME-motor preparation requirement (A,A,then-use);
  (F2) a hidden reversible/toggling preparation state requiring a composed
  motor sequence, with an unrelated clearing motor;
  (F3) unconditional visible direct-goal progress as a negative control.
- Exactly EIGHT UNIQUE role permutations per family (32 matched worlds).
  Generate all 24 action permutations and shuffle with a deterministic
  family-specific derivation from the **first, non-selectable GitHub Actions
  run ID**. Do not inspect or choose mappings before that run.
- Two separately initialized cold ScientificRuntime arms in each world;
  all four physical motors offered every step. Each lifetime: 24 fresh
  episodes with 18 physical actions maximum each; TRUE external restart
  observation only, no hidden state, motor name or tutorial instruction.
  Exactly the same U1 policy/configuration and training/evaluation horizon.
- Every executed physical action incurs actual cost 1 with a fresh safety
  permit, real POST and journal entry. Saved same-runtime checkpoint can
  round-trip. Both arms retain their knowledge over episode restarts.
- No other branch, workflow, user/tool session or repeated run may be used
  to select a better source, code, threshold or seed on this cohort.

## Fixed pass/fail criteria (all mandatory)
1. Candidate beats the baseline total goal successes by **at least 15% of
   baseline successful episodes** (candidate*100 >= baseline*115).
2. **No family** has fewer goal successes than its paired baseline.
3. Candidate uses **at least 10% fewer physical external actions**, no
   external cost increase and no safety-prohibited execution.
4. Across worlds, candidate last-six successes **strictly exceed**
   first-six successes, indicating learning within its cold lifetime.
5. In at least TWO of F0/F1/F2, native U1 must ACTUALLY select at least
   one self-originated option and COMPLETELY execute a real three-motor
   route to a genuine observed goal. Merely offering a plan is insufficient.
6. Negative-control F3 selects ZERO autobiographical options. No externally
   forced choices in any arm; action records, costs and checkpoint all
   reconstruct correctly. Broken integrity is an integrity failure, not PASS.

The raw audit must report every per-world/per-episode action, real POST,
source, option START/COMPLETE, total cost and all family summary fields.
Print an explicit one-use result as PASS/NEGATIVE. Failing a threshold after
the first run cannot be repaired/reseeded and called an independent positive.

## Scope if successful

3-action experience-derived option improving success on new finite-state
synthetic mechanics. It does NOT support external third-party-world transfer,

invention of an evaluation rule, recursive self-modifying Rust/SNN or AGI.
