# Протокол: непрерывность опыта и обучение способа обновления

2026-10-22. База: main `01a35d0c69c3dec0340c753456ada4a7b7f221da`.

До реализации проверены только прежние 64 окна HAR и первые 20% пяти
файлов NAB. Результаты этой разработки не являются подтверждением качества.
Обнаружено, что 59 из 63 соседних окон HAR продолжают предыдущий POST,
но адаптер каждый раз объявлял начало нового эпизода. Проверенные прямые
регрессионные замены сети не дали устойчивого преимущества на разных данных.

## Реализуемая обязанность

В одной сохраняемой жизни получать последовательности исходных наблюдений,
фиксировать прогноз до ответа, учиться временным связям и искать исполняемые
способы обновления модели по шумному опыту. Использовать существующую функцию
поиска RSP2 и её тип политики; точное совпадение всех шумных целей не требовать.
Новый способ обучения может применяться только после проверки на последующих
фактах. Улучшение рекурсивного производителя требует отдельной проверки того,
как новая политика производит следующие полезные политики/способы обучения.

Предсказания, внутренние повторы и виртуальные ученики поиска не считаются
новыми фактами мира. Исходные пиксели и отсчёты относятся к фактическому POST.
Библиотека, история, алгоритмы обновления, RNG и расход вычислений принадлежат
общему runtime. Политика поиска не получает имён корпусов и скрытых меток.

## Уточнение реализации до оценочной части

Оценивается `world_prediction`: общий прогноз, объединяющий исходную сеть и
временную модель. Коэффициент объединения учится по уже полученным ответам
отдельно для физической модальности; имя файла не используется. До очередного
POST фиксируются оба прогноза и использованные коэффициенты. Фиксированный
контроль получает такое же объединение и управление вычислениями.

Поиск изменения алгоритма использует фрагменты по 48 отсчётов: 16 для
адаптации, 32 для проверки. Каждый фрагмент сохраняет действительные веса,
историю и масштаб ошибки перед своим первым отсчётом. В памяти находятся
64 последних фрагмента, 16 выбранных по воспроизводимому случайному приоритету
старых фрагментов и до четырёх контрпримеров отвергнутых изменений. Старый опыт
может использоваться повторно, но не засчитывается как новое подтверждение.

Кандидат обновления проверяется на следующих 128 фактических переходах,
сравнивая полный прогноз до каждого ответа. Для допуска требуется уменьшение
ошибки минимум на 5% и отсутствие ухудшения по модальностям более чем на 2%.
Новая политика поиска проходит прямую и две последующие роли производителя
на фрагментах, начавшихся после её предложения, а затем проверку прежнего
опыта. Это отдельный шумоустойчивый режим существующего RSP2; исторические
счётчики точного режима RSP2 не переписываются.

Дополнительно к критериям ниже требуется фактическое исполнение принятого
алгоритма обновления в основном ученике. Виртуальный кандидат или изменение
поисковой политики без этого не считается приобретённым способом обучения.
Данные уточнения фиксируются до чтения оценочных суффиксов; пороги ниже
не ослабляются.

## Данные и граница оценки

Пять источников выбраны до чтения значений: первый CSV по имени в каждой из
пяти папок настоящих данных NAB. Точные пути, revision и SHA256 находятся в
[манифесте](evidence/continuous-rule-learning/data-sources.json).

Первые 20% разрешены для разработки. Оставшиеся 80% не анализируются до
фиксации исходников и бинарника. Обучение на этой части допускается только
после фиксации прогноза очередного события. После чтения результата исходники
не подстраиваются под эту оценочную часть. Исходные данные публичны;
секретным независимым внешним экзаменом они не объявляются.

Проверяется один организм через все источники с промежуточным сохранением
и продолжением. Контрольные ветви получают те же наблюдения в том же порядке.
Сравнения: последнее значение, среднее последних восьми, обычная AR(8),
та же новая модель с фиксированным способом обучения, полный новый контур.
Предсказание цели не использует текущий POST и метки аномалий NAB.

## Критерии, которые нельзя заменять числом тестов

1. Полная жизнь и воспроизведение состояния проходят; это проверка корректности.
2. Средняя по источникам относительная ошибка нового контура должна быть
   минимум на 5% ниже лучшего единого базового алгоритма; ни один источник
   не должен ухудшиться против последнего значения более чем на 10%.
3. Изменённый способ обучения должен улучшить последующее приобретение
   по сравнению с фиксированным обновлением минимум на 5%, при работе
   целого организма не более 1,5×. Все неудачные поиски включаются в работу.
4. Принятие поисковой политики требует выигрыша и в прямой, и в следующей
   роли производителя, с проверкой сохранения ранее полезного поведения.
   Изменение весов или алгоритма обновления само по себе не считается этим
   результатом. Ноль принятых поколений остаётся нулём.

Ошибка нормируется одинаково для всех алгоритмов. Для сопоставления источников
используется отношение MSE к последнему значению отдельно на каждом источнике,
затем невзвешенное среднее пяти отношений. Публикуются также исходные ошибки,
объёмы наблюдений, память, вычисления и интервалы с временными блоками.
Эти критерии относятся к проверяемой способности обучения прогнозу; создание
общего интеллекта не следует из их прохождения.
