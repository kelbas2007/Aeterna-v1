# COVERAGE-MEMORY-1: продолжение единого организма

Предварительная регистрация до новой оценки. Основание —
[предыдущий аудит и эксперимент](FIRST_READOUT_RESULT.md): приобретение MNIST
сопровождалось ухудшением HAR/Fashion; память потеряла покрытие масок измерений.
Письмо Codex относится к PR18; на момент начала конкретных review-замечаний нет.

## Изменение и границы

В том же Learner включается `organism_enable_coverage_memory`. Лимит остаётся
2048 прототипа и 4 MiB для их хранилища. Сохраняются прежние квоты интерфейса
и знака награды. Внутри положительного раздела выбирается наиболее повторяемая
пара «фактически успешный мотор / маска измерений». Пока есть повторяемая пара,
единственный представитель другой пары не удаляется. Если все пары уникальны,
конечная память не обещает вместить их все. При равенстве предпочитается
вытеснение менее полной маски.

В выбранной паре ограниченная выборка до девяти точек удаляет старший элемент
ближайшей пары. Это инженерная политика хранения, не алгоритм, изобретённый
организмом. Поиск использует имеющуюся нормализацию и до 36 расстояний;
его дополнительная работа учитывается в общей вычислительной работе.
Завершение эпизода обновляет только сохранившиеся прототипы, не возвращает
вытесненные записи. Частоты фактических наград и sketch неудач не сбрасываются.

Режим опциональный; старые состояния без поля политики сохраняют прежние байты
и прежнее поведение. Один U1 остаётся единственным выбирающим действия актором.
Порог RSP2, представление и критерии допуска программ не меняются.

## Новые отложенные строки

После записи обеих жизней замороженные копии treatment, FIFO-контроля и
исходного родителя проходят одну последовательность. Одинаковая жадная политика
вывода, без случайной разведки, обновления модели и корректирующих попыток.
После MNIST проверяется точное сохранение/восстановление.

Проверочные метки не обучают публикуемые живые состояния.

## Критерий и проверки

Полезное улучшение памяти относительно FIFO требует одновременно:

- HAR test: преимущество не менее пяти процентных пунктов;
- MNIST/Fashion test: ухудшение каждого не более двух пунктов;
- суммарно по 768 тестовым задачам — преимущество не менее двух пунктов;
- суммарно в навигации — без потери успехов;
- фактические действия и вычислительная работа обучения не более 125% контроля;
- те же 2048 прототипа, отсутствие архивированных учеников, реальное изменение
  хотя бы одного первого тестового ответа, неизменность моделей во frozen-проверке.

Дополнительно публикуется разность относительно замороженного родителя по
каждому корпусу. Удержание относительно родителя — отдельный критерий: падение
каждого корпуса не более двух пунктов. Провал любой части сохраняется как FAIL.
Выбор treatment основным состоянием допускается только при прохождении обоих
критериев; иначе основным остаётся ранее опубликованный организм PR18.

Отдельный аудитор сверяет все POST с данными и MiniGrid; нативное воспроизведение
обязано повторить выборы, commit и полные состояния. Исходник, исполняемый файл,
данные, родитель, условия и диапазоны связывает машинная регистрация, сохранённая
до запуска. Старые результаты не пересчитываются как результат нового кода.
